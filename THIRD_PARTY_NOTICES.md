# Third-Party Notices

OmniSequence: Transfinite integrates with the following separately installed
Minecraft mods. Their binaries, source files, models and textures are not
bundled in the produced mod JAR:

- Applied Energistics 2, version 15.4.10 for Forge 1.20.1.
- AppliedEnhancements, version 1.0.6-forge.
- ExtendedAE, Forge 1.20.1 (integration tested with 1.4.19).
- Glodium, version 1.20-1.5-forge.
- Advanced AE, Forge 1.20.1 (integration tested with 1.3.6), when installed.
- ExtendedAE Plus and JEI, when installed.

MixinExtras Forge 0.5.3 is bundled using Forge Jar-in-Jar under its MIT license.

The design was informed by GTLCore's Molecular Assembler Matrix implementation.
No GTLCore source files or assets are included in this project.

ExtendedAE Plus' pattern upload implementation was inspected to implement
compatibility through AE2's public PatternContainer API. No ExtendedAE Plus
source files or assets are included in this project.

All resources distributed under the `molecularmanipulator` namespace are
project-authored assets released under the project license.
