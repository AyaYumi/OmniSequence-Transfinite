# 1.21.1 Branch Console / 分支界面布局

OmniSequence 的机器界面和 JEI 页面以本项目 `1.21.1-neoforge` 分支的 `b9916fb18646d59409d0b77991984c6c621399d5` 为布局参考，对照该分支的 Java 屏幕、LDLib2 XML 和 AE2 屏幕定义重构。Forge 1.20.1 使用原生控件及共享绘制代码实现对应分区、槽位、操作区和分页，不依赖新版客户端 API 或 LDLib2 覆盖层。

材质语言参考 Minecraft 1.21.1 对应的 AE2 19.2.17：冷灰紫面板、白色细槽框、深紫灰输入框和浅青蓝选中状态。参考来源为该版本的 `guis/pattern_provider.png`、`guis/text_field.png`、`gui/sprites/button*.png` 和 `screens/common/palette.json`。

为满足文字清晰度要求，灰底按钮使用深色文字，输入框使用无阴影浅色文字。Minecraft / AE2 继续负责容器行为、文本编辑和同步。

| 层级 | 规则 |
| --- | --- |
| 窗口 | 冷灰紫背景，深紫灰外边与白色内边；面板、按钮、输入框和 JEI 卡片统一使用直角 |
| 内容 | 按参考分支的功能区使用平面细框：普通分区为灰色细框，强调区域为白色细框，内嵌区域为灰紫底色 |
| 操作 | 普通按钮为灰紫底深色字；主操作、当前标签和悬停采用浅青蓝高亮，边缘参考 AE2 按钮的像素层次；所有文字关闭阴影 |
| 输入 | 深紫灰文本框、无阴影浅色内容、浅色光标和青蓝焦点线，保留原版编辑、选区和校验行为 |
| 库存 | 灰紫的 18×18 槽位配白色细框，输出槽增加蓝色边界；物品仍按 Minecraft 的 16×16 尺寸绘制 |
| 状态 | 蓝色表示选择和操作，青色用于进度，绿/金/红分别表示成功、等待/告警和错误 |
| JEI | 独立冷灰卡片，研究标题条、材料流程、时间/能耗分层；结构材料数量置于模型下方的深紫灰底白字标签，避免遮挡浅色物品 |

输出接口的六方向按钮左侧显示对应邻接方块的 16×16 缩略图，右侧显示方向；悬停说明邻接名称、输出状态和世界坐标方向。流体方块无物品形态时使用流体图标，空位或未加载邻接有对应提示。邻接查询只在客户端 tick 进行，图标及提示仅在方块状态或方向开关变化时重建。

物质重写页的分解和复制按钮高亮分别绑定菜单同步的 `deconstructEnabled` 与 `rewriteEnabled`。
关闭时使用普通按钮样式，开启后即使暂时等待材料、网络或冷却也继续显示开启状态；不以某一帧的 `RUNNING` 状态代替开关状态。

## Implementation

- `OmniUiTheme` 负责窗口、区域、按钮表面、输入框、槽位和状态条的基础绘制。
- `MachineUiLayout` 集中保存全部机器的固定分区和槽框位置，与 AE2 屏幕 JSON 逐项校验；布局对象只创建一次，绘制时遍历固定数据。
- `OmniButton` 复用 Minecraft 的点击、键盘及提示机制，独立绘制所有操作状态。
- `ConsoleTextRenderer` 统一无阴影按钮文字和溢出裁切；输入框使用每控件复用的绘制适配器，保留原版光标的一个像素返回值补偿，防止光标两侧文字重叠，同时保留选区绘制。
- `OmniToggle` 用于独立自动合成通道的开关。
- `ConsoleSlotBackground` 让 JEI 输入和输出槽位保持一致。
- `StructureMaterialRenderer` 使用 24×27 的 JEI 命中区域，16×16 模型下留出数量标签；材料列距 27、行距 28，预览高度为两行材料和 JEI 页头预留空间。
- `ResponsiveContainerScreen` 在窗口不足时统一转换绘制与输入坐标，AE2 的槽位和菜单事件仍由原有容器处理。
- AE2 15 不支持新版 `shouldAddToolbar` 接口，通过旧版 `getHelpTopic` 接口抑制自动帮助页签，避免出现参考分支未包含的工具栏。
- 寰宇计算图案由三个旋转矩形与一个中心方块绘制，替代参考分支逐扫描线绘制菱形的循环；不增加渲染目标或后处理。

不引入 LDLib2、XML UI、模糊或额外渲染目标。按钮状态直接由菜单数据驱动。搜索继续使用原有索引与节流；样板总数在服务端仅随样板修订变化重新统计，避免逐帧扫描和翻页计数失真。

## 隔离验证

`ConsoleTextRenderingTest` 在无窗口、无 OpenGL 的测试进程中执行真实按钮文字路径和 Minecraft `EditBox` 绘制，检查阴影标志、单次文字绘制、光标间距、选区替换、输入滚动以及缩放矩阵。`ConsoleContrastTest` 检查文字对比度；`StructureMaterialRenderingTest` 和 `StructurePreviewInteractionTest` 检查数量标签、命中区域、两行材料边界和预览交互。记录器使用确定性字宽；这些检查不替代资源包字体和游戏 GPU 渲染的运行时验证。

`MachineUiLayoutTest` 验证六类机器及研究分页的屏幕尺寸、槽框与菜单槽位的一像素偏移、多个窗口尺寸下的绘制边界及矩阵恢复。`NeighborPreviewTest` 验证六个独立邻接缩略图、方向文字预留空间及空位占位绘制。完整布局预览使用外部测试夹具和样例状态，夹具不进入发布 JAR。
