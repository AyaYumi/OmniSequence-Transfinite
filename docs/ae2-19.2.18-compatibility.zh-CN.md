# AE2 19.2.18 兼容记录

配套版本：Applied Enhancements `1.1.0`、OmniSequence
`2.0.7`。Minecraft 1.21.1、Java 21、NeoForge 21.1.220。
两个模组均改用 AE2 19.2.18 编译，继续声明 AE2 `[19.2.17,)`。

## 上游核对与修复

比较官方 `neoforge/v19.2.17` 与 `neoforge/v19.2.18` 标签。
`appeng/api` 下没有源码变动。内部变更涉及 CPU 列表、数量工具、容器持久化、
配方填充、凝聚器、外部库存取料、Ponder 和 Jade 集成。

- AE2 删除了 `CPUSelectionList.formatStorage`。Applied Enhancements 原有必需注入
  会因此导致客户端加载失败。现在在 `drawBackgroundLayer` 的最终容量文本调用上
  处理无限标记；协处理器沿用最终调用处理。普通数量保留 AE2 自身的格式。
- 两版均保留三个 `InfoBar.add(String, int, float, int, int)` 调用，分别用于任务数量、
  空闲容量、协处理器。修复使用必需注入，未通过忽略失败隐藏注入位置漂移。
- `Tooltips.units`、`DECIMAL_NUMS`、`BYTE_NUMS` 改为私有。两个模组未引用它们。
- 外部库存取料新增了循环中的物品类型复查。Applied Enhancements 的候选槽位优化
  继续调用 AE2 的 `extractFromHandler`，因此保留这项修复。
- Omni CPU 的批量接口、核心逻辑、样板供应器和名称缩写注入目标未变。
  Omni 使用更新后的独立 Applied Enhancements 前置，不嵌入它的实现。

客户端运行：

```powershell
.\gradlew.bat --no-configuration-cache -I tools/ui/ae2-compat.init.gradle runClient
.\gradlew.bat --no-configuration-cache '-Pae2_version=19.2.17' -I tools/ui/ae2-compat.init.gradle runClient
```

先把任一可进入的隔离测试世界复制到
`build/ae2-compat-client-run/saves/AE2Compatibility`。探针自动处理首次无障碍欢迎页，
渲染真实 CPU 控件并断言最终文本、名称和提示；报告和截图位于
`build/reports/ae2-compat-<AE2版本>/`，完成后退出。仅 opt-in 测试源集加载探针和
捕获 Mixin，不进入发行 JAR。

服务端专项运行：

```powershell
.\gradlew.bat --no-configuration-cache -I tools/gametest/ae2-compat.init.gradle runGameTestServer
```

## 未通过的完整回归

完整 18 项多方块 GameTest 有 15 项通过，以下三项在 19.2.17 与 19.2.18 都失败，
新建隔离世界仍可复现，不能作为本次升级的新增回归或已通过项：

- `genericInputsSurviveAssemblyLifecycle`：组装器在线或真实 CPU 投送断言失败。
- `storageBusExposesOnlySupportedMainPatterns`：模拟/检查库存的不变性断言失败。
- `cablesIndependentCpusAndPortableJobs`：测试世界中的方块实体类型或已初始化节点
  重载断言失败。

19.2.18 的新世界完整回归还在关服区块卸载阶段停滞，线程转储保存到
`build/ae2-compat-server-shutdown-threads.txt`；确认进程属于本次隔离测试后终止。
专项服务端、AdvancedAE 和客户端测试均正常退出。
没有在用户个人存档或完整整合包运行中验证全部可选扩展。
