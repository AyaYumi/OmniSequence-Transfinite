# OmniSequence: Transfinite 2.0.5

Minecraft 1.21.1 · NeoForge · Java 21

## Native UselessMod BigInteger output return

The UselessMod BigInteger bridge now retries a capacity result that cuts
through a smart-doubling wrapper. It rounds the uncommitted native admission
down to the largest complete wrapper-task count and asks UselessMod again.
Successful native batches therefore keep their CPU binding and return
intermediate outputs directly to the exact CPU, avoiding the ordinary
Long.MAX_VALUE segmented ME insertion path.

The bridge still rejects a permanently invalid or zero-sized admission, and
the caller's input ledger remains untouched when no complete task can be
admitted.
