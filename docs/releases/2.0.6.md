# OmniSequence: Transfinite 2.0.6-forge

## English

This Forge 1.20.1 release synchronizes the 2.0.6 feature set from the 1.21.1 line.

- Adds the Molecular Auto Crafter with pattern slots, output buffering, adjacent export, and configuration screens.
- Adds machine recipe importing and index refresh support for Forge recipe JSON.
- Preserves exact AE quantities and BigInteger crafting accounting across the Forge port.
- Adds AE inputs and outputs to Matter Fabrication recipes and their JEI/GuideME views.
- Adds optional multiblock force-loading configuration and ExtendedAE Plus matrix upload integration.

Required runtime dependencies are AE2 15.4.10+, ExtendedAE, Glodium, GuideME, and AppliedEnhancements `1.0.9-fix-forge`.

## 中文

本 Forge 1.20.1 版本同步 1.21.1 分支的 2.0.6 功能集：

- 新增带样板槽、产物缓存、相邻方块导出和配置界面的物质自动合成机。
- 新增 Forge 配方 JSON 的机器配方导入与索引刷新支持。
- 在 Forge 移植中保留精确 AE 数量和 BigInteger 合成核算。
- 构筑井配方支持 AE 输入与 AE 输出，并同步 JEI/GuideME 展示。
- 新增多方块强制加载配置，以及 ExtendedAE Plus 矩阵上传兼容。

运行时必需前置包括 AE2 15.4.10+、ExtendedAE、Glodium、GuideME，以及 AppliedEnhancements `1.0.9-fix-forge`。
