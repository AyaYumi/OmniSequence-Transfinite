# 太虚天仪特效预览

本版采用玉白、淡金、冰蓝的建筑配色。中央八瓣分面晶簇围绕原有核心旋转，上下浮晶与
外围十二枚碎晶形成空间层次；三道倾斜星轨带有刻度和渐隐流星，外层共振波缓慢扩散。

下环的光流向内汇聚，中环依次点亮竖立符纹，上环释放升腾晶光。八塔错峰播放从塔底
爬升到塔顶的光脉，随后沿弧线传入中央。环与塔装饰使用真实组件角度和升降偏移。

点击“启动运动”后，约八秒内依次展开塔阵、三环与中央天仪；暂停和恢复时亮度与流速
平滑变化，归位时降低能量。实体累计运动进度决定启动阶段，重新进入世界不会把已运行
建筑当成首次启动。客户端过渡状态不进入存档，也不增加网络同步包。

特效统一绘制，不新增粒子实体。晶体表面写入深度，光带保留场景深度测试；两种专用
渲染层都关闭背面裁剪，光带无需重复提交背面。静态方块材质和运动网格沿用已安装版本。
完整档光带在测试相位使用 54,464 个顶点、晶体表面 704 个；简化档分别为 12,992 和 320。
顶点数随流光位置略有变化。原有特效档位和距离降级继续生效。

## 验证

- 8 项特效单元测试通过，覆盖几何范围、顶点预算、矩阵恢复、时钟循环、环塔变换和启停过渡。
- 4 项服务端 GameTest 通过，包含位置更新后的包围盒、碰撞、乘载、归位及材料所有权回归。
- 使用整合包的六个渲染模组和 Complementary Reimagined r5.8.1 完成实际客户端预览。
- 48 帧位置同步 / 光影切换检查全部通过，最低实体纹理边缘比例 0.230。
- 截图前采样的平均帧时间为 16.76、16.93、16.80 ms；测试客户端上限 60 FPS。
  此数据属于固定视角和该测试环境，不代表任意整合包场景的帧率。

截图与动图位于 `build/taixu-tianyi-final/`，验证结果为该目录下的 `verification.json`。
日志为 `build/taixu-tianyi-final.log`、`build/taixu-tianyi-flicker.log`、
`build/taixu-tianyi-gametest.log`，单元测试报告为 `build/reports/tests/test/`。

## 交付

预览包以当前整合包的 2.0.7 JAR 为基线，仅更新太虚实体、特效绘制与客户端过渡的六个
类条目，保留基线内其他条目的内容。输出文件为
`build/libs/omnisequence-transfinite-2.0.7-taixu-tianyi-preview.jar`。
安装采用同目录暂存后原子替换，旧版保存在整合包 `codex-backups/` 内；安装收据记录
基线与补丁校验值、实际安装路径和备份路径。加载新 JAR 需要完全退出并重启 Minecraft。
