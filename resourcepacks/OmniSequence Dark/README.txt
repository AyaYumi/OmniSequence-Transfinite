OmniSequence Dark GUI

This optional resource pack changes the OmniSequence GUI to the dark theme.
It replaces the default osq_light assets with the matching dark artwork and layouts.

Normal install:
1. Install OmniSequence: Transfinite. This pack is bundled inside the mod JAR.
2. Enable "OmniSequence: Dark GUI (Built-in)" in Options > Resource Packs.
3. Move it above other packs that replace OmniSequence GUI resources.

No separate ZIP is required. Disabling the pack restores the default light theme.
The standalone ZIP is an optional export for redistribution only.

Requires OmniSequence: Transfinite for Minecraft 1.21.1.
