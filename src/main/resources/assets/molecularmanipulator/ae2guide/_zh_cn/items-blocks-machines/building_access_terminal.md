# 建筑访问终端

一个手持终端，集中访问本模组各座建筑的真实控制界面。每个终端最多保存 **64 座建筑**，同类型的多座机器也可分别绑定。

## 使用

1. 手持终端，**潜行右键建筑控制器**，将其加入列表。物质构成机端口、样板装配口也可单独绑定；星算引擎可通过成型外壳、观测口或有效锚绑定内部核心。
2. **手持终端右键空气**打开建筑列表。列表显示建筑名称、维度、坐标和当前访问状态，用鼠标滚轮或拖动列表右侧滚动条浏览，不分页。
3. 点击建筑打开原有控制界面；界面左上角的 **返回建筑列表** 可切换至其他建筑。
4. 列表中的 **移除** 只删除此终端的绑定，不会拆卸建筑或清空库存。

目录沿用机器界面的纸色卡片与青绿配色：左侧同时显示五条完整记录，用滚轮逐条滚动或拖动滚动条定位；右侧显示绑定数量、可访问／不可用数量及使用提示。名称或坐标过长时会省略显示，悬停建筑可查看完整信息；移除按钮与打开区域分开。

终端支持分子构序重写阵列、构序阵列、构序自动合成器、物质构成机及其四类服务端口和样板装配口、星算引擎／九环星仪、万象演算核心，以及视界奇点枢纽的多方块与单方块形态。没有独立控制界面的装饰块、结构部件和超限算枢不作为列表项。

## 访问条件

- 玩家与建筑须处于 **同一维度**，目标的 **服务端区块须已加载**。终端不自动强制加载区块。
- 不要求站在控制器旁边，也不受客户端渲染距离限制。
- 建筑的 ME、能源、成型、研究、物品消耗与玩家操作权限要求保持不变。星算引擎仍需成型才可打开。
- 控制界面的库存、遥测与按钮使用原有服务端菜单，不复制物品，不创建第二座机器。移走终端、删除控制器或卸载目标区块后，已打开的访问会关闭。
