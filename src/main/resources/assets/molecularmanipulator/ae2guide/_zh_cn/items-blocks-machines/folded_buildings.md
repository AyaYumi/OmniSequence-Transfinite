# 折叠建筑与整机搬迁

建筑包裹能把整座机器作为一件物品携带。新建筑可在 ME 下单，用星图定标器选址展开。已有机器则从自身界面回收成包，连同库存搬到新位置，也能跨越同一存档内的维度。

从左到右是空间折叠装配器、建筑包裹和星图定标器。装配器用于订购包裹，定标器用于选址展开，可重复使用。

## 准备什么

- 新建时：装配器、能自动合成的 ME 网络、建筑的控制器与全部建材。装配器本身用普通 AE2 材料制作，第一座构筑井之前即可获得；建筑材料仍按各自配方和研究要求准备。
- 搬迁时：已安装的机器、星图定标器，以及一个空背包格，用来领取回收包裹。
- 目的地：足够大的空地、允许施工的范围和足够高度。不要只给控制器留一格位置。

### 新建包与封存包

| 包裹 | 里面是什么 |
| --- | --- |
| 从 ME 订购的新建包 | 标准建筑，包含控制器与完整建材。构筑井的可选接口与样板总成另行安装。 |
| 从机器回收的封存包 | 实际使用的整台机器，包含接口、总成、库存、流体、设置、研究、加工进度和无线绑定。 |

包裹物品和世界存档中的建筑档案都要保留。备份或转移世界时，带上整个世界文件夹。只把包裹复制到另一个存档，不能带走建筑。

## 第一步：在 ME 订购新建筑

1. 将**空间折叠装配器**接入有电、有物品存储和合成 CPU 的 ME 网络。
2. 在 ME 终端中查找并订购所需建筑包。不需要另给装配器放样板。
3. ME 消耗该建筑的**控制器和全部标准建材**，完成后交付一个包裹。把它取到背包里。

| 可订购的完整建筑包 | 布局与用料 |
| --- | --- |
| 物质构筑井 | [物质构筑井](matter_fabrication_well.md) |
| 构序阵列 | [构序阵列](sequence_array_controller.md) |
| 万物演算核心 | [万物演算核心](omni_computation_core.md) |
| 视界奇点天枢 | [视界奇点天枢](event_horizon_singularity_hub.md) |
| 天体仪 L1、L2、L3 | [星算引擎](star_computation_engine.md)；均为完整建筑，包含中央、基座和前 1、2、3 环。升级时另行准备所需材料。 |

JEI 结构分类列出完整材料与包裹产物，可旋转、平移、缩放和分层查看。创造模式也有这七种新建包。天体仪 **L0、L4～L9** 包由整机回收获得，不能直接订购。

## 第二步：用定标器选址展开

1. **包裹放背包，定标器拿手上，右键场地。** 在面板选择要展开的包裹。
2. 用 X/Y/Z 按钮调整位置，用旋转按钮改变水平朝向。每次移动 1 格，按住 Shift 每次移动 8 格。
3. 先看高度：**基面 Y 是建筑最低实体方块的高度**，不是控制器高度。天体仪核心在**基面 Y + 37**；天枢主控在**基面 Y + 65**，天枢整体为 **97×97×129 格**。
4. 检查世界投影：**浅蓝是建筑位置，金色是外边界，红色是冲突**。把障碍清干净，光井等必须留空的位置也不能堵住。
5. 点击**确认空间折叠展开**，等待地基、建筑和核心依次落位。恢复期间机器暂停；成功后包裹消耗，定标器保留。

按 Esc 可收起面板，走近检查投影。定点仍保留，再次右键定标器会回到原选址，即使瞄准别处也不会换址。要重新选址，先点“取消定点”。已经开始的施工会继续。

展开过程中，包裹暂时留在背包原位，不能移动。需要撤回施工时，重新打开定标面板，点击“中断回收建筑”。清理结束后，原包裹可以再次展开。不要自行拆掉半成品。

## 搬迁已有机器

1. 等施工、拆除或升级结束。完成或取消所在 ME 网络的外部 CPU 合成任务，等材料、产物和退款结清。天枢还需停止采集。
2. 打开机器自身界面，选择“回收包裹”或对应回收入口，按提示确认。天体仪与天枢两次点击间隔约 **0.25～3 秒**。
3. 领取一个封存包裹。背包满时腾出一格，再在空中使用定标器领取。
4. 在同一存档的目的地按第二步展开，恢复所选 ME 连接和外部管道，检查库存与设置后再开工。接口朝向随建筑旋转。

物质构筑井、构序阵列、多方块万物演算核心、视界奇点天枢和已成型天体仪支持整机回收。超限算枢与单方块奇点天枢不使用此入口。右键定标器会打开选址面板，不能直接拆除机器。

封存保留物品、流体、样板、催化剂、投入材料、加工进度、待交付产物、退款和无线绑定。外部 ME CPU 的合成任务不会随包迁走，需要先结清。

无线接收机展开后，继续保持外部 ME 电缆已移除、量子槽为空。两端区块已加载，且归属和权限仍匹配时，原绑定可重新连接；无线不会加载区块。如果拆掉、移动或替换构序无线枢纽本身，它会获得新身份，需要逐台重新绑定接收机。详见[无线枢纽设置](sequence_array_controller.md)。

天体仪回收包按回收时从第一环起连续完整的实物环数标为 L0～L9，与最初购买的等级无关。天枢先让运动部件安全归位，再封存整机，需要保持运动范围加载且没有障碍。回收请求跨重启保留，发起玩家返回后可继续；取消回收会撤销封存，安全归位仍会完成。展开后需手动重启采集。

## 怎样算成功

- 新建：ME 订单交付一个有建筑名称的包裹；展开完成后，原地出现完整建筑，包裹消耗。
- 搬迁：旧址机器已回收，新址可打开机器界面，库存、流体、样板与设置都保留。封存包在定标面板中的“封存清单”可用来核对部件。
- 每份封存建筑只能展开一次；复制包裹物品不会多出第二台机器。

## 卡住时先看这里

| 现象 | 怎么处理 |
| --- | --- |
| ME 找不到包裹 | 检查装配器是否接到有电的网络，终端是否显示可合成物品。 |
| 无法确认展开 | 等选址检查完成，清除红色冲突，检查高度、世界边界和施工权限。 |
| 再次右键仍是旧位置 | 点击取消定点后，再重新选址；Esc 只收起面板。 |
| 点了取消定点，施工还在继续 | 重新打开面板，使用中断回收建筑。 |
| 机器提示忙碌，无法回收 | 结束施工或研究／演算任务，结清外部 ME CPU 任务；天枢还需停止采集并归位。 |
| 封存包提示档案不可用 | 保留包裹，检查是否仍在原存档；从包含完整世界文件夹的备份恢复档案。 |

服务器中断后，未完成的搬迁会在重启后继续。要改换场地，使用面板中的中断回收，并保留仍在施工的包裹。
