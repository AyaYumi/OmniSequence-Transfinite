# 折叠建筑与整机搬迁

**建筑包裹把一整座机器变成一件可携带的物品。** 新建筑可以在 ME 中下单，用星图定标器选址展开； 已有机器则从自身界面回收成包，连同库存一起搬到新位置，也能跨越**同一存档内的维度**。

从左到右：**空间折叠装配器负责接单 → 建筑包裹负责携带 → 星图定标器负责选址展开**。定标器可以反复使用。

## 准备什么

- 新建时：装配器、能自动合成的 ME 网络、建筑的控制器与全部建材。装配器本身用普通 AE2 材料制作，第一座构筑井之前即可获得；建筑材料仍按各自配方和研究要求准备。
- 搬迁时：已安装的机器、星图定标器，以及一个空背包格，用来领取回收包裹。
- 目的地：足够大的空地、允许施工的范围和足够高度。不要只给控制器留一格位置。

### 先分清新建包与封存包

| 包裹 | 里面是什么 |
| --- | --- |
| 从 ME 订购的新建包 | 一座标准建筑，包含控制器与完整建材；不是空壳，也不是免费建造。 构筑井的可选接口与样板总成另行安装。 |
| 从机器回收的封存包 | 你实际使用的整台机器，包含已装接口、样板总成、库存、流体、设置、研究与加工进度等。 |

**封存包裹是手上的道具，建筑档案是存档中保存的完整机器内容，两者都要保留。** 收好包裹；备份或搬走世界时带上**整个世界文件夹**。只把包裹复制到另一个存档，不能带走建筑。

## 第一步：在 ME 订购新建筑

1. 将**空间折叠装配器**接入有电、有物品存储和合成 CPU 的 ME 网络。
2. 在 ME 终端中查找并订购所需建筑包。不需要另给装配器放样板。
3. ME 消耗该建筑的**控制器和全部标准建材**，完成后交付一个包裹。把它取到背包里。

| 可订购的完整建筑包 | 布局与用料 |
| --- | --- |
| 物质构筑井 | [物质构筑井](matter_fabrication_well.md) |
| 构序阵列 | [构序阵列](sequence_array_controller.md) |
| 万物演算核心 | [万物演算核心](omni_computation_core.md) |
| 视界奇点天枢 | [视界奇点天枢](event_horizon_singularity_hub.md) |
| 天体仪 L1、L2、L3 | [星算引擎](star_computation_engine.md)；分别带前 1、2、3 环，均包含完整中央结构与基座，**不是升级差额包**。 |

JEI 的结构分类列出完整材料与包裹产物，可旋转、平移、缩放和分层查看。 创造模式也有这七种新建包。天体仪 **L0、L4～L9** 包由整机回收获得，不能直接订购。

## 第二步：用定标器选址展开

1. **包裹放背包，定标器拿手上，右键场地。** 在面板选择要展开的包裹。
2. 用 X/Y/Z 按钮调整位置，用旋转按钮改变水平朝向。每次移动 1 格，按住 Shift 每次移动 8 格。
3. 先看高度：**基面 Y 是建筑最低实体方块的高度**，不是控制器高度。天体仪核心在**基面 Y + 37**；天枢主控在**基面 Y + 65**，天枢整体为 **97×97×129 格**。
4. 检查世界投影：**浅蓝是建筑位置，金色是外边界，红色是冲突**。把障碍清干净，光井等必须留空的位置也不能堵住。
5. 点击**确认空间折叠展开**，等待地基、建筑和核心依次落位。恢复期间机器暂停；成功后包裹消耗，定标器保留。

**想走远一点查看投影？按 Esc 收起面板即可。** 定点仍保留，再次右键定标器会回到原选址，即使瞄准别处也不会换址。只有**取消定点**才允许重新选址；它不会中断已经开始的施工。

展开过程中包裹会暂时留在背包原位，不能移动。 需要撤回未完成的施工时，重新打开定标面板，点击**中断回收建筑**。等清理结束后，原包裹可以再次展开，不要自行拆掉半成品。

## 已有机器：先回收，再按第二步展开

1. **先结清任务。** 等施工、拆除或升级结束；完成或取消所在 ME 网络的外部 CPU 合成任务，等材料、产物和退款结算。天枢还需先停止采集。
2. 打开机器自身界面，选择**回收包裹**或对应回收入口，按提示确认。天体仪与天枢需再次点击确认，两次间隔约 **0.25～3 秒**。
3. 领取一个封存包裹。若背包已满，腾出一格，再在空中使用定标器领取。
4. 在同一存档的目的地按第二步展开，重新接好外部 ME 线缆和管道，检查库存与设置后再开工。接口朝向随建筑一起旋转。

支持整机回收：**物质构筑井、构序阵列、多方块万物演算核心、视界奇点天枢和已成型天体仪**。超限算枢与单方块奇点天枢不使用此入口。 右键定标器只打开选址面板，不会直接拆掉机器。

机器内部的物品、流体、样板、催化剂、投入材料、加工进度、 待交付产物和退款随封存保留；**外部 ME CPU 的合成任务不会随包迁走**，所以要先结清。

天体仪回收包按回收时**从第一环起连续完整的星环**标为 L0～L9，不看最初购买的包裹等级。 天枢则先让运动部件安全归位，再封存整机； 保持运动范围加载且没有障碍。 回收等待跨重启保留，发起玩家返回后可继续； 取消回收只撤销封存，安全归位仍会完成。天枢展开后需手动重启采集。

## 怎样算成功

- 新建：ME 订单交付一个有建筑名称的包裹；展开完成后，原地出现完整建筑，包裹消耗。
- 搬迁：旧址的机器已回收，新址可以打开机器界面， 库存、流体、样板与设置还在。封存包在定标面板中的**封存清单**可用来核对封存部件。
- 每份封存建筑只能展开一次；复制包裹物品不会多出第二台机器。

## 卡住时先看这里

| 现象 | 怎么处理 |
| --- | --- |
| ME 找不到包裹 | 检查装配器是否接到有电的网络，终端是否显示可合成物品。 |
| 无法确认展开 | 等选址检查完成，清除红色冲突，检查高度、世界边界和施工权限。 |
| 再次右键仍是旧位置 | 点击取消定点后，再重新选址；Esc 只收起面板。 |
| 点了取消定点，施工还在继续 | 重新打开面板，使用中断回收建筑。 |
| 机器提示忙碌，无法回收 | 结束施工或研究／演算任务，结清外部 ME CPU 任务；天枢还需停止采集并归位。 |
| 封存包提示档案不可用 | 保留包裹，检查是否仍在原存档；从包含完整世界文件夹的备份恢复档案。 |

服务器中断后，未完成的搬迁会在重启后继续。 若想改换场地，使用面板中的中断回收，而不是丢掉仍在施工的包裹。
