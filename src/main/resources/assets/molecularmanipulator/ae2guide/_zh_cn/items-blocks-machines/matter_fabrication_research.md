# 构筑井研究与深度研究

研究可以解锁新的构筑井配方；重复研究同一分支，则能让该分支一次加工更多份配方。

## 先准备什么

- 建好[物质构筑井](matter_fabrication_well.md)，连接有电、有存储的 ME 网络。
- **研究材料必须存入这个 ME 网络。背包和输入口里的材料都不会用于研究。**
- 进度属于这座井，第二座井需要单独研究。
- 第一次先选**Ⅰ阶：AE 基础构筑**。首轮需要**压印器 ×4、充能器 ×4、赛特斯石英水晶 ×256、福鲁伊克斯水晶 ×128，以及逻辑、运算、工程处理器各 ×64**。

## 一步步完成首次研究

1. 打开控制器，切到**研究**页。
2. 在左侧选择**Ⅰ阶：AE 基础构筑**，查看**AE 库存 / 本轮需求**和前置要求；滚动材料列表，确认看到了全部材料。
3. 把本轮材料全部存入 ME，再点击**解锁研究**。开始时会一次性扣除本轮材料。
4. 保持结构、网络和供电正常。默认首轮需要 **30 秒、256 AE/t**。
5. 看到完成次数变成 **1 / 9**，就能制作[样板总成](matter_fabrication_pattern_assembly.md)，并使用解锁的 AE 加工配方。

再做一轮时，点击**深度研究**。手动开始的研究可以**暂停研究**、**继续研究**，已经支付的材料和进度都会保留。电力足够时，不同分支能同时研究。

## 下一项该选什么？

![主线研究路线：AE 基础分出星髓和扩展材料，两条Ⅲ阶汇合后通往视界、恒星和超限](../assets/diagrams/research-route-zh_cn.png)

箭头表示“先完成哪项”。两条Ⅲ阶路线最终汇合；可选结晶和异态物质支线未画入主线。

没有特别注明次数的前置，完成一轮即可。下表是默认时间和功率； 整合包调整后，以研究页显示为准。

| 研究 | 先完成 | 主要用途 | 秒 / AE 每 tick |
| --- | --- | --- | --- |
| Ⅰ · AE 基础构筑 | 无 | AE 加工、样板总成、分子自动合成器 | 30 / 256 |
| Ⅱ · 星髓材料工程 | AE 基础 | 板、处理器、晶粉、合金、星讯组件和后续星位锚 | 45 / 512 |
| Ⅱ · 扩展材料工程 | AE 基础 | 推进科技所需的 ExtendedAE 材料和部件 | 45 / 512 |
| Ⅱ · 量子材料工程 | 扩展材料 | 推进科技所需的 AdvancedAE 材料和部件 | 60 / 1024 |
| Ⅲ · 构序工程 | 扩展材料 + 星髓材料 | 构序设备、重写设备、无限构序存储与无限并行矩阵 | 60 / 1024 |
| Ⅲ · 演算架构 | 量子材料 + 星髓材料 | 演算设备与全知演算矩阵 | 90 / 2048 |
| Ⅳ · 视界物质工程 | 构序工程 + 演算架构 | 黑洞、白洞和天枢建材 | 90 / 4096 |
| Ⅴ · 恒星核心工程 | 视界物质 | 微型超新星、天枢控制器、白洞资源核心 | 120 / 8192 |
| Ⅵ · 超限集成工程 | 恒星核心 | 超限算枢 | 180 / 16384 |
| 可选 · 星讯诱导结晶 | 星髓材料 | 用可复用的无瑕母岩，将星讯和水制成水晶 | 60 / 512 |
| 可选 · 异态物质学 | AE 基础 | 幽灵物质与引力水晶 | 30 / 256 |

**一直用自然生长的水晶也能推进。** 星讯诱导结晶是可选分支；基础星髓加工不需要星讯或无瑕母岩。

### 把其他机器的配方交给构筑井

联动机器研究要求两个Ⅲ阶分支都**至少完成三轮**：构序工程 **3 / 9**，演算架构也 **3 / 9**。首轮算在三轮内，光是到达Ⅲ阶还不够。

所有默认联动机器和整合包追加的机器导入都遵守这个条件，实际生产时也会检查。Ⅱ阶扩展、量子材料提供到达这些分支所需的起步配方。 安装对应模组后，才会出现相应联动研究。

### 另一个入口：星算天体仪研究

[星算引擎](star_computation_engine.md)是一座**九环天体仪**，不是另放一个小立方体。默认星算研究菜单只有**单方块集成**：将天体仪升至 **L3** 后，仍需**主动解锁**，费用是 **0 bit**。

这一项只额外限制**分子构序重写阵列**和**超限算枢**；它们原有的井内研究条件仍须满足。 默认情况下， 三种矩阵、星位锚和分子自动合成器都不额外要求星算研究解锁。

## 让 ME 自动备料

网络中需要对应样板、原料和可用合成 CPU。

| 按钮 | 会做什么 |
| --- | --- |
| **下单** | 准备下一轮材料，齐全后自动开始研究。 |
| 按住 **Shift** → **一键下单到满阶** | 显示并准备全部剩余轮次的总材料，一次研究到满阶。 |
| 备料时点**停止当前研究** | 取消备料和未完成材料订单，将保留材料退回 ME。 |

**下单研究一旦正式开始，就不能停止或暂停。** 下单到满阶会支付所有剩余轮次材料，但只进行一次研究计时， 使用该分支显示的功率。点击前先看总费用；ME 已满时，待退材料会保留等待。

## 大批量生产：全部九轮

所有默认研究都有**九轮**，包括异态物质学和联动机器研究。首轮解锁配方，后续提高**并行数，也就是同时能加工多少份配方**，不会缩短单份耗时。

| 已完成轮数 | 并行上限 |
| --- | --- |
| 1 | 1 |
| 2 | 256 |
| 3 | 65,536 |
| 4 | 16.78M |
| 5 | 4.29G |
| 6 | 1.10T |
| 7 | 281.47T |
| 8 | 72.06P |
| 9 | 9.22E |

每次都查看下一轮的材料列表：扩产轮次有自己的费用， 不会照搬首次购买机器的材料。 实际批量仍受原料、供电和产物空间限制。

生产速度由控制器所在 ME 网络上的星算引擎提供，不缩短研究计时。不需要研究的基础配方一直可用，并采用 AE 基础构筑已完成轮次的并行上限；未完成研究前，一次只做一份。

## 成功时看哪里

完成次数增加，该分支的配方变得可用； 继续研究后，界面显示的并行数也会提高。 配方解锁列表可以查看这个分支能生产什么。

## 不工作时先查这些

| 问题 | 处理方法 |
| --- | --- |
| 背包有材料，库存却显示零 | 存入控制器连接的 ME 网络，不是输入口。 |
| 无法解锁或继续深度研究 | 检查全部前置次数、当前 ME 库存、结构和联网状态。 |
| 联动机器研究仍锁着 | 两个Ⅲ阶分支都要完成三轮。 |
| 自动备料一直等 | 打开**详情**，查看缺少的样板、原料和可用 CPU。 |
| 研究进度不走 | 恢复结构、网络和足够的供电；已付款材料和进度仍保留。 |
| 阵列或算枢配方仍锁着 | 同时检查井内研究和天体仪 L3 的**单方块集成**解锁。 |
