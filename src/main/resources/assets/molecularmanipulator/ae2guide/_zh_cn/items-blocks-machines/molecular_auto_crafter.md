# 分子自动合成器

分子自动合成器能让 ME 常备指定数量的成品。放入已编码样板、设好目标数量后，它会从 ME 库存取料制作，适合补充木板、处理器等常用物品。

左边是设备，右边是可用的合成、锻造、切石样板。需要外部机器的处理样板不适用。

补货在设备内部完成，不需要合成 CPU。先把原料存进 ME，设备不会为缺少的原料下单。九个样板槽可以分别设置和启停，共享本机的制作能力。

## 准备

- 在[构筑井](matter_fabrication_research.md)完成一轮Ⅰ阶：AE 基础构筑，再制作设备。默认无需额外解锁星算研究。
- 准备有电、有物品存储的 ME 网络，并留出 1 个空闲频道。
- 在样板编码终端制作一张“橡木原木 → 橡木木板”合成样板，准备 32 个橡木原木和成品存储空间。

## 让 ME 常备 64 个木板

1. 放下设备并接入上述 ME 网络，把 32 个原木存入 ME。想从零开始补货，可先取出网络里已有的橡木木板。
2. 放入木板样板，点击该槽的齿轮，或右键样板，打开设置。
3. 把“成品上限”设为 64，原木的“保留量”设为 8。这样只会使用超过保留量的原木。
4. 保持“ME输出”，库存统计选“ME 网络库存”。填写后点击“保存全部”，也可逐项点击“设定”或按 Enter 提交，确认界面不再显示“未保存”。
5. 返回主界面，点击该槽的“启动”按钮。其他槽可先保持关闭，成品会送入 ME。
6. 木板达到 64 个后会暂停；取走一些木板，设备就会自动补回。原木不足以在保留 8 个的前提下完成下一份配方时，会停下等料。

**上限 0 表示不限量。** 想停机就关闭该槽，或取出样板。原料保留量 0 表示可以用完这种原料。

### 输出到旁边的箱子

</Row>

在设备旁放箱子，将输出切换为“附近容器输出”，再打开“输出方向”，启用箱子所在的面。原料仍从 ME 取，成品和返还容器会送到所选的相邻容器。

| 库存统计方式 | 什么时候适合用 |
| --- | --- |
| 实际输出目标库存 | 想让所选箱子补到目标数量；会统计已启用方向上相邻容器里的同种成品。 |
| ME 网络库存 | 想按网络中已有成品数量决定是否开工；即使输出到箱子，也只看 ME 库存。 |

原料超过一页时，用设置页的原料翻页按钮继续设置。填写保留量后同样要提交。

每批都要留出足够空间接收成品和返还物，输出目标已满时会暂停。星算引擎可提高本机的制作并行量；构筑井深度研究提高的是井内制作这台设备时的配方并行量。

## 补货没有按预期运行时

| 看到的情况 | 怎么处理 |
| --- | --- |
| 没有开始制作 | 检查电力、频道、样板和该槽的启动开关；确认数值已经提交。 |
| 等待原料，ME 明明还有一些 | 检查保留量。只有超过保留量、且够完成一份配方的材料才会使用；缺少的中间材料不会自动下单。 |
| 达到上限后不动 | 这是正常暂停；取走成品或提高上限即可继续。 |
| 箱子已经有货，却仍在制作 | 检查库存统计是否选了“ME 网络库存”；要按箱子数量补货，改选“实际输出目标库存”。 |
| 输出受阻 | ME 输出时检查存储空间；附近容器输出时检查箱子、启用方向和空位，也要给返还容器留空间。 |
| 数值没有生效 | 点击“设定”或“保存全部”，或在输入框内按 Enter；只移开鼠标或关闭页面不会提交。 |

## 无线连接与搬迁

在右侧栏用“远程连接”绑定构序无线枢纽，连接条件见[无线枢纽设置](sequence_array_controller.md)。

正常拆下设备会保留内部内容和无线绑定。重新放置后恢复 ME 连接；如果无线枢纽被移动或替换，需要重新绑定。

## 下一步

[构序阵列](sequence_array_controller.md)的“自动合成”页也有九个独立补货槽，目标和原料保留量的含义相同，成品送回 ME。阵列的主样板库接收终端订单，使用时要将样板放进对应区域。

想从终端指定制作数量，可使用[分子构序重写阵列](molecular_sequence_rewrite_array.md)，并给网络配一台合成 CPU。
