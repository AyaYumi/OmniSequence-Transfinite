# 引力水晶与幽灵物质

引力水晶可改变附近玩家的重力方向，或推动生物与掉落物。幽灵物质是可放置的危险物质，也是制作引力水晶时保留的催化剂。

## 解锁与制作

完成一阶研究后，在构筑井研究**特殊: 异态物质学**。该研究只有一轮，默认耗时 **30 秒**、功率 **256 AE/t**。

研究消耗赛特斯石英水晶 ×64、福鲁伊克斯水晶 ×32、紫水晶碎片 ×32、铜锭 ×64、末影珍珠 ×16。

| 产物 | 消耗材料 | 保留催化剂 |
| --- | --- | --- |
| 幽灵物质 ×4 | 末影珍珠 ×8、荧石粉 ×16、赛特斯石英水晶 ×16 | 无 |
| 引力水晶 ×1 | 紫水晶碎片 ×16、铜锭 ×8、福鲁伊克斯水晶 ×4 | 幽灵物质 ×1 |

两种加工配方均为 **10 秒、256 AE/t**。将幽灵物质放入同井任意[样板总成](matter_fabrication_pattern_assembly.md)的**催化剂**页，即可供同井总成制作引力水晶。催化剂不消耗，不写入处理样板，批量加工也不增加其需求。

## 使用引力水晶

水晶可安装在六个方向的方块表面，无需能源。默认**吸引**模式将玩家的重力指向安装面，可以在墙面和天花板上站立、行走与跳跃；生物和掉落物会被拉向安装面。

| 操作或条件 | 效果 |
| --- | --- |
| 空手右键 | 切换吸引与推离模式 |
| 红石信号 | 暂停引力场，移除信号后恢复 |
| 作用范围 | 以水晶为中心的 5×5×5 区域 |
| 实体墙壁 | 阻挡引力场 |
| 创造飞行或旁观者 | 不受引力场影响 |

将水晶放在地面并切换为**推离**，可建立升降通道。多个引力场相接时，玩家可以沿不同表面移动。

用镐可拆下并取回水晶。离开引力场、暂停或拆除水晶、进入水中、骑乘或开启创造飞行后，会恢复普通重力。

## 放置幽灵物质

幽灵物质需要下方方块支撑，无法直接挖掘。它会伤害周围约 **3×3×3** 范围内的生物，伤害穿透护甲；实体墙壁可以阻挡。掉落物、创造与旁观玩家不受伤害。

破坏支撑方块会使幽灵物质碎裂，不掉落物品，并留下持续 **一分钟**的危险雾气。重新放回支撑方块不会恢复幽灵物质。

## 用水抑制

水桶或自然流水可使幽灵物质含水，抑制危险区域。撤去水源后，水退去时危险恢复。浸在水中或气泡柱中的生物也受到保护。

碎裂后留下的雾气仍按原定的一分钟期限消散。物品栏或催化剂页中的幽灵物质不会造成伤害。
