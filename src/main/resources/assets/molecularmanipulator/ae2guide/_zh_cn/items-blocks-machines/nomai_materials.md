# 引力水晶与幽灵物质

引力水晶能让你在墙上行走或搭建升降通道； 幽灵物质是制作它时可反复使用的材料，但放进世界后会成为危险区域。

左边是引力水晶，右边是幽灵物质。**背包和催化剂槽中的幽灵物质不会伤人；用来加工时不需要把它放出来。**

## 先准备什么

- 在[物质构筑井](matter_fabrication_well.md)完成**Ⅰ阶：AE 基础构筑**。
- 首次研究**特殊: 异态物质学**，需要向该井的 ME 网络存入**赛特斯石英水晶 ×64、福鲁伊克斯水晶 ×32、紫水晶碎片 ×32、铜锭 ×64、末影珍珠 ×16**。背包和输入口不提供研究材料。
- 安装[样板总成](matter_fabrication_pattern_assembly.md)，用来放可复用的催化剂，并按下方配方准备加工原料。
- 测试引力时选一面低墙，留出活动空间和安全落地区域。

## 一步步做出引力水晶

1. 打开井的**研究**页，选择**特殊: 异态物质学**；首轮材料存入 ME 后，点击**解锁研究**。
2. 持续提供 **256 AE/t、30 秒**，完成首轮。这是可选分支，共九轮；解锁两种配方只需第一轮。
3. 用**末影珍珠 ×8、荧石粉 ×16、赛特斯石英水晶 ×16**，在井中加工出 **4 份幽灵物质**。
4. 把其中**一份幽灵物质**放入同井任意总成的**催化剂**页。它是可复用工具，不是消耗原料；一份就能供全井使用，批量加工也不需增加。
5. 编码引力水晶处理样板，只写**紫水晶碎片 ×16、铜锭 ×8、福鲁伊克斯水晶 ×4 → 引力水晶 ×1**，再从 ME 下单。

两条加工配方的基础参数均为 **20 秒、256 AE/t**，实际耗时计入星算引擎加速。不要把幽灵物质填进处理样板的消耗原料。

## 使用水晶：先从低墙试起

1. 把水晶装在想站立的表面上：地面、墙面或天花板都可以，**不需要能源**。
2. 先保持默认的**吸引**模式，走近安装面。进入范围后，重力会指向这个表面，你就能在上面站立、行走和跳跃。
3. 空手右键水晶，切换到**推离**。地面上的水晶在这个模式会向上推动，可做升降通道。
4. 提供红石信号可以**暂停**，移除信号后恢复；用镐能拆下并取回水晶。

| 引力场规则 | 搭建时要注意什么 |
| --- | --- |
| 以水晶为中心的 **5 × 5 × 5 范围** | 单块距离较短，长路线需要衔接多个引力场。 |
| 实体墙壁会阻挡 | 水晶和玩家或物体之间要留出通路。 |
| 生物与掉落物 | 会被拉动或推动；吸引模式会改变玩家重力方向。 |
| 创造飞行或旁观模式 | 这些玩家不受影响。 |

离开引力场、关闭水晶、进入水中、骑乘或开启创造飞行后， 玩家恢复普通重力。测试墙面和天花板时，先安排安全落地。

安装 Antarchy 时，它的强制重力、反重力和切换过程优先于水晶吸引；释放控制后，水晶才会接管。

## 如果要把幽灵物质放出来

**先准备水，并让生物远离，再放置。** 幽灵物质需要下方方块支撑，会伤害附近约 **3 × 3 × 3** 范围内的生物，穿透护甲。实体墙壁可以阻挡，掉落物、创造和旁观玩家不受伤害。

- **用水抑制：**水桶或自然流水可以使它含水，停止危险效果。生物浸在水或气泡柱中也能受到保护。
- **不要随意撤水：**水退去后，危险会恢复。
- **清理方法：**不能直接挖幽灵物质；拆掉支撑会让它碎裂，**不掉物品**，并留下持续**一分钟**的危险雾气。保持水覆盖，等待雾气消散。

重新补上支撑不会恢复原来的沉积物。水只压制残留雾气，不会重置或延长消散时间。

## 成功时看哪里

井里产出引力水晶，幽灵物质仍留在催化剂槽中。 走近吸引模式的墙面水晶，可以站在墙上；切到推离后会被推开。 含水的幽灵物质则不再伤害附近生物。

## 不工作时先查这些

| 问题 | 处理方法 |
| --- | --- |
| 引力水晶加工一直等 | 完成异态物质学，把幽灵物质放进本井总成的**催化剂**页，不是输入口。 |
| 引力场似乎没开 | 移除红石信号，靠近水晶并清理实体遮挡，确认吸引或推离模式。 |
| 玩家没有转到墙上 | 停止创造飞行，离开水或坐骑，并检查 Antarchy 是否正在控制重力。 |
| 拆掉支撑后仍受伤 | 雾气会持续一分钟，用水压制并等待。 |
| 撤水后又开始受伤 | 水只抑制危险，不会销毁幽灵物质。 |
