# 引力水晶与幽灵物质

引力水晶能让你在墙上行走，也能用来搭建升降通道。幽灵物质是制作水晶时可反复使用的催化剂，放进世界后会伤害附近生物。

左边是引力水晶，右边是幽灵物质。幽灵物质放在背包或催化剂槽中不会伤人，加工时留在槽内即可。

## 先准备什么

- 在[物质构筑井](matter_fabrication_well.md)完成Ⅰ阶：AE 基础构筑。
- 首次研究“特殊: 异态物质学”需要赛特斯石英水晶 ×64、福鲁伊克斯水晶 ×32、紫水晶碎片 ×32、铜锭 ×64、末影珍珠 ×16。将这些材料存入该井连接的 ME 网络，背包和输入口不提供研究材料。
- 安装[样板总成](matter_fabrication_pattern_assembly.md)存放可复用催化剂，并按下方配方准备加工原料。
- 初次使用引力水晶时，选一面低墙，留出活动空间和安全落地区域。

## 一步步做出引力水晶

1. 打开井的“研究”页，选择“特殊: 异态物质学”。首轮材料存入 ME 后，点击“解锁研究”。
2. 持续提供 256 AE/t，等待 30 秒完成首轮。这是可选分支，共九轮，解锁两种配方只需第一轮。
3. 用末影珍珠 ×8、荧石粉 ×16、赛特斯石英水晶 ×16，在井中加工出 4 份幽灵物质。
4. 把其中一份幽灵物质放入同井任意总成的“催化剂”页。它可供全井复用，批量加工也只需一份。
5. 编码引力水晶处理样板，消耗原料填紫水晶碎片 ×16、铜锭 ×8、福鲁伊克斯水晶 ×4，产物填引力水晶 ×1，再从 ME 下单。

两条加工配方的基础耗时均为 20 秒，耗电 256 AE/t，星算引擎可缩短加工时间。幽灵物质留在催化剂槽中，不要填入处理样板的消耗原料。

## 使用水晶：先从低墙试起

1. 将水晶装在想站立的地面、墙面或天花板上，无需能源。
2. 保持默认的“吸引”模式，走近安装面。进入范围后，重力会指向这个表面，你就能在上面站立、行走和跳跃。
3. 空手右键水晶，切换到“推离”。地面上的水晶会向上推动，可用来搭建升降通道。
4. 红石信号会暂停水晶，移除信号后恢复。用镐可拆下并取回水晶。

| 引力场规则 | 搭建时要注意什么 |
| --- | --- |
| 以水晶为中心的 **5 × 5 × 5 范围** | 单块距离较短，长路线需要衔接多个引力场。 |
| 实体墙壁会阻挡 | 水晶和玩家或物体之间要留出通路。 |
| 生物与掉落物 | 会被拉动或推动；吸引模式会改变玩家重力方向。 |
| 创造飞行或旁观模式 | 这些玩家不受影响。 |

离开引力场、关闭水晶、进入水中、骑乘或开启创造飞行后，玩家恢复普通重力。在墙面和天花板上使用时，先安排好落地位置。

安装 Antarchy 时，它的强制重力、反重力和切换过程优先于水晶吸引；释放控制后，水晶才会接管。

## 在世界中放置幽灵物质

**先备好水、让生物远离，再放置。** 幽灵物质需要下方方块支撑，会伤害附近约 3 × 3 × 3 范围内的生物，伤害穿透护甲。实体墙壁可以阻挡，掉落物、创造和旁观玩家不受伤害。

- 用水桶或自然流水使它含水，就能停止危险效果。生物浸在水或气泡柱中也能受到保护，水退去后危险会恢复。
- 清理时需要拆掉支撑，无法直接挖取幽灵物质。它会碎裂，不掉物品，并留下持续一分钟的危险雾气。保持水覆盖，等待雾气消散。

重新补上支撑不会恢复原来的沉积物。水只压制残留雾气，不会重置或延长消散时间。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 引力水晶加工一直等 | 完成异态物质学，把幽灵物质放进本井总成的**催化剂**页，不是输入口。 |
| 引力场似乎没开 | 移除红石信号，靠近水晶并清理实体遮挡，确认吸引或推离模式。 |
| 玩家没有转到墙上 | 停止创造飞行，离开水或坐骑，并检查 Antarchy 是否正在控制重力。 |
| 拆掉支撑后仍受伤 | 雾气会持续一分钟，用水压制并等待。 |
| 撤水后又开始受伤 | 水只抑制危险，不会销毁幽灵物质。 |
