# 模拟灯笼

这盏灯既能手提、落地照明，也能让你进入**个人临时模拟**。最实用的用途是：**拿着亮灯，按住 G 约 1 秒再松开，然后亲自挖微瑕星髓母岩，得到永久无瑕母岩。**

左边是手里的灯笼，右边是放在地上的灯笼； 两者都能提供模拟中的灯光。以下使用默认键位，可在控制设置中调整。

## 准备什么

- 一盏灯笼：工作台配方需要**星髓合金锭 ×4、星髓晶体 ×1、木棍 ×1、铁粒 ×2**。
- 一块**微瑕星髓母岩**和一把镐。较低品质的母岩不能用这个方法变成无瑕。
- 干燥的站立位置；人泡在水里时不能进入模拟。模拟无需燃料或 AE。

## 一步步获得无瑕母岩

**微瑕母岩 → 进入亮灯模拟并挖取 → 无瑕母岩。** 不是拿灯笼右键母岩。

1. 把灯笼拿在主手或副手。未点亮时，按 **B** 点亮。
2. 按住 **G** 约 1 秒，再松开，进入模拟。此时你仍在原来的世界和维度。
3. 建议按 **F** 把灯换到副手，主手拿镐；也可以按 **V** 把灯放在地上，腾出手来。
4. **亲自挖取微瑕母岩**，得到无瑕母岩。创造模式也可在模拟中用中键取方块。
5. 将得到的无瑕母岩放下，它会保持无瑕，不再掉级。 母岩无需处在灯光范围内，只要你仍在模拟中。

## 怎样算成功

你看到的微瑕母岩变为无瑕外观，挖出的物品也叫**无瑕星髓母岩**；退出模拟后再放置，它仍然是无瑕。

模拟不会把地上的原母岩直接改成无瑕。 它在被挖走前仍正常长芽，也可能掉级； 若已掉成更低品质，就无法获得无瑕。 其他未进入模拟的玩家，以及自动采掘设备，不能代替你完成这次转化。

## 放灯、拿回和退出

| 操作 | 默认按法与结果 |
| --- | --- |
| 点亮／熄灭 | **B** 优先操作手中灯笼；手中没有灯笼时，操作准星对着的地面灯。 |
| 放到地上 | **V** 放在目标方块的顶面，下方须有支撑；干燥放置会保留亮灭状态。 |
| 拿回 | 留出一只空手，右键地面灯。两手都满时不会拿走灯笼。 |
| 退出模拟 | 用 **B** 熄灭一盏亮灯，仅退出按键的玩家；熄灭地面灯也会让其他人失去那盏灯的光。 |

**模拟中，手上的灯笼不能丢出、存进容器或换到别的快捷栏格。** 这是正常操作限制，不是道具丢失。按 F 换到副手后，主手仍能换工具；按 V 放下也能腾出手。

手持亮灯时进水，会灭灯并退出模拟。 地面灯进水只会熄灯，不会让你退出；排掉水后才能再点亮。 下线、死亡或换维度也会退出模拟，但地面灯和掉落物仍保留， 重新登录不会自动进入模拟。

## 为什么有时全黑，有时有绿色网格

模拟灯笼的亮区半径为 **10 格**，边缘逐渐变暗，手提灯和地面灯都算。

- **人在任意亮区内**：照到的表面正常，未照到的地方纯黑，看不到绿色网格。
- **把灯放下，走出所有亮区**：暗处会出现深绿色网格和轮廓；远处被灯照到的表面仍正常。
- **走回亮区**：网格再次消失。手中始终拿着亮灯，就始终在亮区内。

判断依据是**你站在哪里**，不是准星看向哪里。火把和日光不会改变这条边界。

## 进阶探索：离讯之境

这是一个**真实、可建造且会保存的虚空维度**，不是临时画面。初次抵达时，脚下只有 **1 块基岩**。**先备好搭建方块与跨维度返回手段；灯笼不会自动把你送回去。**

1. 在任意维度手持亮灯，按住 G 约 1 秒再松开，进入模拟。
2. 按 V 放下灯，离开**所有**亮灯的 10 格范围，自己或其他玩家手中的亮灯也算。保持模拟，不要按 B 熄灯退出。
3. 跳入该维度底部虚空，符合条件时，会在受到原版虚空伤害前抵达离讯之境。**没有进入模拟或仍在亮区时，普通虚空仍会伤害你。**

抵达后模拟结束，手中灯笼不再锁定。 这里永夜、没有天然地形，空中有彩色字符流。时间每隔随机 **5～15 秒**在 **0.5 倍速与 2 倍速**之间切换；这里的玩家、生物与机器一起变速，其他维度不受影响。 再次来访不会清空你搭建的内容。

## 不顺手时先看这里

| 现象 | 怎么处理 |
| --- | --- |
| G 没反应 | 确认手持亮灯、不在水里，按住约一秒后松开；检查键位冲突。 |
| 切不了工具或丢不了灯 | 模拟锁住了手中灯笼，按 F 换到副手，或按 V 放下。 |
| 放不下灯 | 瞄准方块顶面，检查支撑、空间与施工权限。 |
| 看不到绿色网格 | 先放下灯，并走出所有亮灯的 10 格范围。 |
| 挖出仍不是无瑕 | 确认仍在模拟、由你亲自挖取，且目标还没有从微瑕继续掉级。 |
