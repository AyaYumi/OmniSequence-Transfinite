# 模拟灯笼

模拟灯笼可以提在手里或放在地上照明。用它进入短暂的个人模拟，就能取得永久的无瑕星髓母岩。

<BlockImage id="molecularmanipulator:simulation_lantern" scale="4" />
</Row>

以下使用默认键位，可在控制设置中调整。

## 准备什么

- 用**星髓合金锭 ×4、星髓晶体 ×1、木棍 ×1、铁粒 ×2**制作灯笼。
- 准备一块**微瑕星髓母岩**和一把镐。母岩品质较低时，先用晶种修到微瑕。
- 站在干处再进入模拟，无需燃料或 AE。

## 取得无瑕母岩

<ItemImage id="molecularmanipulator:flawed_star_marrow_parent_rock" scale="4" />

<ItemImage id="molecularmanipulator:simulation_lantern" scale="4" />

<ItemImage id="molecularmanipulator:flawless_star_marrow_parent_rock" scale="4" />
</Row>

1. 主手或副手拿灯笼，未点亮时按 **B** 点亮。
2. 按住 **G** 约 1 秒后松开，进入模拟。你仍在原来的维度。按键没反应时，检查是否有键位冲突。
3. 主手拿灯时，按 **F** 把灯换到副手，再拿起镐。
4. **亲自挖下微瑕母岩**，得到无瑕星髓母岩。创造模式也可用中键取方块。只要还在模拟中，就可以在灯光范围外挖取。退出模拟后，挖到的无瑕母岩也不会掉级。

在模拟中，微瑕母岩会显示为无瑕。挖下之前，原地的母岩仍会长芽和掉级。若已掉到微瑕以下，挖下时会得到实际品质的母岩。自动采掘也只会得到实际品质的母岩。

## 放灯、拿回和退出

| 操作 | 默认按法与结果 |
| --- | --- |
| 点亮或熄灭 | 按 **B** 优先操作手中的灯。手中没灯时，对准地上的灯再按。 |
| 放到地上 | 对准有支撑且留有空间的方块顶面，按 **V** 放下。你需要当地的放置权限。在干处放下时，灯会保留原来的亮灭状态。 |
| 拿回 | 留出一只空手，右键地上的灯。 |
| 退出模拟 | 按 **B** 熄灭一盏亮灯，你的模拟就会结束。地上的灯熄灭后，其他人也会失去这盏灯的光。 |

模拟期间，手中的灯锁在手上。按 **V** 放下灯就能腾出手。退出模拟后才能丢出灯、存入容器或移动到其他快捷栏格。

手持亮灯时进水会灭灯并退出模拟。放在地上的灯进水只会熄灭，排水后才能重新点亮。下线、死亡或换维度也会退出模拟，地上的灯和掉落物会留在世界里。

## 灯光与绿色网格

在模拟中，手提灯和地面灯的照明范围都是 **10 格**。站在任意一盏灯的亮区内时，没照到的地方会变黑。走出所有亮区，暗处就会出现绿色网格和轮廓。走回灯光下，网格会消失。只有模拟灯笼的光算在内。

## 进入离讯之境

离讯之境是一个能建造并保存建筑的虚空维度。初次抵达时，脚下只有 **1 块基岩**。**出发前带上搭落脚点的方块，另外准备跨维度返回的办法。**

1. 在准备离开的维度进入模拟。
2. 按 **V** 放下手中的灯，走出所有亮灯的范围。其他玩家手中的灯也算。保持模拟开启。
3. 跳进当前维度底部的虚空。满足以上条件时，你会在受到虚空伤害前抵达。**没进入模拟或还在亮区时，虚空仍然会造成伤害。**

抵达后模拟结束。离讯之境没有天然地形，始终是夜晚。时间在 **0.5 倍速和 2 倍速**之间交替，每次间隔随机为 **5～15 秒**。变速只影响该维度的玩家、生物和机器。
