# 天枢资源采集

在资源采集页点击“开始采集”，天枢就会同时生产列表中的全部资源，并自动存入 ME。默认产物以粗矿、原木等为主，无需选择单一目标，也无需放入样品或微型黑洞。

## 准备什么

- 已成型的[视界奇点天枢](event_horizon_singularity_hub.md)，或已接网的[单方块天枢](compact_singularity_hub.md)。
- 有电、有频道的 ME 网络，以及能接收列表中全部资源的物品存储。
- 保持所需区块加载。多方块天枢还需要完整、无障碍的运动范围。

资源采集不消耗奇点序质，也无需流体存储。复制指定样品或生产序质的操作见[物质复制](singularity_matter_duplication.md)。

## 一步步开始采集

1. 右键天枢，打开“资源采集”页，确认网络在线。
2. 浏览当前资源列表，检查 ME 是否能收下每一种物品。任意一种产物存不进去，都会使整轮采集停住。
3. 点击“开始采集”。多方块天枢需要先完成启动、让运动部件就绪，单方块天枢可直接采集。
4. 采集页显示正在采集后，ME 中的多种资源会一起增加，产物不会掉到地上。

默认每 20 tick（正常速度下约 1 秒），列表中的每一种资源各产出 **1000 个**。例如同时列有粗铁和橡木原木，两者每轮就各增加 1000 个。重复条目只计一次。

服务器可调整资源范围、排除名单、单次数量和间隔，以界面当前显示为准。客户端配置不会改变服务器的产物列表。

## 停止与再次开工

- 点击“停止采集”即可停止供货，多方块天枢会让运动部件归位。
- 黑洞产液和样品复制在物质复制页独立运行，需要分别停止。
- 区块暂时不可用，或重启后 ME 正在重新连接时，保持所需范围加载并等候。
- 缺块、断网或施工可能使采集停止。修复后查看界面，若仍显示停止，就重新点击“开始采集”。
- 存储不足时会暂停，物品不会洒在地上；恢复后也不会补发停产期间的产量。

## 采集没有产物时

| 现象 | 怎么处理 |
| --- | --- |
| 资源列表为空或没有想要的物品 | 清单由服务器选择；确认整合包包含该资源，并请服主查看采集范围和排除名单。 |
| 显示采集中，却没有产物 | 等待启动完成，再检查 ME 物品容量与存储过滤，所有产物都要能存。 |
| 多方块天枢无法启动或归位 | 清除运动路径障碍，并加载整个运动范围的区块；可用强加载或其他加载方式保持运行。 |
| 重启后暂时没产出 | 等 ME 完成连接；若恢复后采集已停止，手动再次开始。 |
| 改采集速度，复制仍没加快 | 采集与复制是两套功能，见[物质复制](singularity_matter_duplication.md)。 |

在机器的资源采集页点击“指南”，可随时回到本页。
