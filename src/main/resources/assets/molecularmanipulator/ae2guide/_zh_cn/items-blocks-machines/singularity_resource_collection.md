# 天枢资源采集

**点一次开始，天枢就同时生产列表中的全部资源，并自动存入 ME。** 默认以粗矿、原木等资源为主，不需要选择单一目标，也不需要放样品或微型黑洞。

## 准备什么

- 已成型的[视界奇点天枢](event_horizon_singularity_hub.md)，或已接网的[单方块天枢](compact_singularity_hub.md)。
- 有电、有频道的 ME 网络，以及能接收**所有列表资源**的物品存储。
- 保持所需区块加载。多方块天枢还需要完整、无障碍的运动范围。

这项功能不消耗奇点序质，也不需要流体存储。想复制指定样品或生产序质，请看[物质复制](singularity_matter_duplication.md)，不要用“开始采集”代替那一页的操作。

## 一步步开始采集

1. 右键天枢，打开**资源采集**页，确认网络在线。
2. 浏览当前资源列表，检查 ME 是否能收下每一种物品。只为粗铁预留空间、却挡住其他产物，会使整轮采集停住。
3. 点击**开始采集**。多方块天枢先等待启动、运动就绪；单方块天枢无需这段建筑运动。
4. 打开 ME 终端，查看列表中的资源数量是否增加。

默认每 **20 tick**（正常速度下约 **1 秒**），**每一种资源各产出 1000 个**，不是所有资源合计 1000 个。列表中的重复资源只计一次，不必来回切换目标。

## 怎样算成功

采集页显示正在采集，ME 中多种资源一起增加。 例如列表含粗铁和橡木原木时，两者都会按各自的单轮数量增长。 产物不会从核心掉到地上。

如果服务器调整了资源范围、排除名单、单次数量或间隔， 按界面当前显示为准。客户端自己的配置不会改写服务器的产物列表。

## 停止与再次开工

- 点击**停止采集**即可停止供货，多方块天枢会让运动部件归位。
- 停止采集**不会**停止黑洞产液或样品复制；它们在物质复制页独立运行。
- 区块暂时不可用、重启后的网络正在连接时，先保持范围加载并等候。
- 缺块、真正断网或施工可能让采集停止。 修复后看一下界面，若仍显示停止，就重新点击开始采集。
- 存储不足时不会把物品洒在地上，也不会在恢复后补发停产期间的轮次。

## 不工作时先看这里

| 现象 | 怎么处理 |
| --- | --- |
| 资源列表为空或没有想要的物品 | 清单由服务器选择；确认整合包包含该资源，并请服主查看采集范围和排除名单。 |
| 显示采集中，却没有产物 | 等待启动完成，再检查 ME 物品容量与存储过滤，所有产物都要能存。 |
| 多方块天枢无法启动或归位 | 清除运动路径障碍，并加载整个运动范围的区块。强加载开关本身不是运动许可。 |
| 重启后暂时没产出 | 等 ME 完成连接；若恢复后采集已停止，手动再次开始。 |
| 改采集速度，复制仍没加快 | 采集与复制是两套功能，见[物质复制](singularity_matter_duplication.md)。 |

在机器的资源采集页点击**指南**，可随时回到本页。
