# 星算引擎

星算引擎现在只使用**九环天体仪**结构。L0 必须同时具备**完整的中央 3×3×3 结构**（1 个主核、22 个外壳、4 个观测端口）与 **928 个实体基座方块**；即使基座完整，中央缺任何一件也不能成型。再从内到外安装完整星环，逐级提升到 L9。它为同一 ME 网络提供生产增益，并通过配方树解锁团队永久配方；旧立方体不能独立成型，旧四向锚柱不再支持。

## 搭建

1. 先在 JEI 的**天体仪结构**分类查看 L1/L2/L3 布置和完整材料。可手工照图搭建，也可按下文流程订购完整建筑包后展开。
2. 搭好实体基座，将**星算引擎核心**放在基座最低层上方 **37 格**。按下方布局，在核心周围放齐 **22 个外壳和 4 个观测端口**，组成中央 **3×3×3**。只有中央结构与基座都完整，才会自动成型为 L0。
3. 按核心朝向对应的固定槽位，从第一环开始连续安装星位锚。每环完整、材质正确且前面的环均完整后，才计入亮环数和等级；不能跳环。
4. **成型本身**不需要右键或供能；网络增益与研究操作则需要有电、已分配频道的有效 ME 连接。

### 必需的中央 3×3×3 结构

- **正中心放 1 个星算引擎核心（主核）**，北、南、东、西四个水平朝向面的中央各放 **1 个观测端口**，其余 **22 个位置填满引擎外壳**。27 个位置都必须有真实方块，观测端口不是留空的洞口。
- 以主核为 `(0, 0, 0)`，中央结构占三个方向偏移 -1 至 +1 的全部位置。观测端口位于 `(±1, 0, 0)` 与 `(0, 0, ±1)`，除这四处和主核外，其余位置均为外壳。
- 这是天体仪的中央，**不是可独立运行的小立方体机器**。中央任何部件缺失或放错，都会像基座缺块一样阻止 L0 成型及整机增益；中央与基座齐全后，才按星环计算等级。

### 实体镂空环架基座

- 用 520 个**星仪雕纹基座**和 408 个**星仪鎏金基座**，合计 **928 个真实方块**；普通金块和引擎外壳不能替代。
- 以核心为原点计算水平偏移 `x`、`z` 和半径 `r = sqrt(x² + z²)`。底座外径 **37 格**（半径 18），只占 Y=-37、-36、-35、-34 四层，中央 `r <= 5` 的竖井四层全空。

| 相对核心 Y | 实体方块轮廓 | 方块数 |
| --- | --- | ---: |
| -37 | 反重力环 `7 < r <= 10`、外环 `15 < r <= 18`，加上 `5 < r <= 18` 且满足 `abs(x) <= 1` 或 `abs(z) <= 1` 的四向 3 格宽窄桥 | 552 |
| -36 | 中圈 `12 < r <= 14` 与井沿 `5 < r <= 7` | 240 |
| -35 | 仅井沿 `5 < r <= 7` | 68 |
| -34 | 仅井沿 `5 < r <= 7` | 68 |

- 各环与井沿的外缘一格宽、四向窄桥的中线用金边，其余用雕纹基座；精确布局可在 JEI 中分层查看。
- **缺一块或放错材质都会停止成型和增益**，补齐后自动恢复；右击未成型的核心，会告诉你缺什么方块、在哪个坐标。

**成型后的样子**

- **中央 3×3×3 的实体仍在原位**。成型后隐藏中央 **26 件（22 个外壳和 4 个观测端口）**的原网格，由主核显示一个 **3×3×3 整体模型**；这些方块及方块实体、碰撞和掉落都保留，不会移除或消耗材料，失去成型时恢复普通外观。
- 未成型时底座就是冷灰石板／深蓝灰细金边的普通方块。成型后也会隐藏**这 928 个底座方块**的外观，继续显示原有的悬浮金属环架、正面悬浮宝石和能量井；这些方块的碰撞和掉落都保留，拆开结构或移除核心即恢复原貌，材料不损失。**环与环之间的空隙是真正空的**，不会像旧版那样撞到实心台阶；但旧布局留下的方块或你自己额外放的方块仍然有碰撞，需要手动拆掉。
- 环体按服务端确认的连续亮环数逐个出现：L0 不显示，L3 显示前三环，L9 显示全部九环。已点亮的环面会绕核心翻转、进动，环上的镶嵌水晶跟着环一起动。基准／量子／终末三阶分别使用青绿、紫、金材质。
- **120 格刻度盘**悬浮在核心下方、微微倾斜，缓慢自转；其余底座部件不动。
- 真实功能锚仍在原搭建坐标，供选取、接线和升级，旁边的小标记不随环运动。

**动态效果**

客户端**动态效果**设置（0 关闭、1 精简、2 完整）控制动画和细节。**至少点亮一环**后，可启用刻度盘旋转、星云向内流动、水墨井面和数据雨：

- **等级 0**：保留静态整机、星云和底座。
- **等级 1**：启用上述效果，使用精简细节。
- **等级 2**：增加更细的细节、环带镶嵌水晶和近距离锚位辉光。

流动速度跟随引擎的真实状态：断网／待机时 **0.35 倍**，作为有效 ME 网络中选中的在线引擎时 **1 倍**，正在真实付费超频时 **2 倍**；信息耗尽或断网会降回慢档。效果会随视距和世界雾效淡出。

**已有世界**

旧核心会在服务端刷新时改用天体仪规则，**旧立方体不能独立成型**，旧四向锚柱不再支持。需要核对中央 27 件，手动补齐任何缺件与真实基座，再按环布置星位锚；团队永久解锁不会因此清除。

原有外壳和观测端口仍是**必需的中央结构件**，也保留原配方中的材料用途。只有被服务端确认为已成型天体仪中央成员的部件，才提供所属真实主核的菜单与 ME 连接；散放件不接网、不代理菜单。更新不会自动删除玩家方块；仍有碰撞的多余旧方块需自行拆除。

已封存的整机档案仍按原内容恢复，不改写内容，不凭空补件、退款或免费换成更大的等级包。旧立方体档案恢复后，同样要满足完整中央 3×3×3 与真实基座要求，缺件须手动补齐。旧的未封存小模板包不能再作为新建筑部署，也不会免费换成材料更多的 L1/L2/L3 包。

`star_orrery_l0`～`star_orrery_l9` 是开发用结构模板，不是生存模式建筑包的获取流程。**模板重放只适合一次性的测试世界**：其中的方块和空气写入可能覆盖已有建筑，切勿在主存档的建筑上重放模板。

## ME 接网与界面

把真实 ME 线缆接到**核心、有效中央外壳或观测端口、有效环上星位锚**即可接网。中央部件和星位锚必须属于这座已成型天体仪，并由服务端确认归属；它们都代理**同一真实主核的 ME 连接**，不是独立引擎。基座和散放的外壳、观测端口不提供这种连接。整座引擎是**一个网络设备**，占用 **1 个频道**，闲置耗能 **16 AE/t**，不是每个入口各占一个频道。这是真实 AE2 接网，不是装饰性的连线指示。

右键**已成型的核心、有效中央外壳或观测端口、有效环上星位锚**，会打开同一真实主核的实时界面。界面只有**两个页签**：

- **总览**：显示结构与 ME 状态、有效算力与等级、三类有效锚数量、四项网络增益图标，以及网络信息库存和实际 bit/t 消耗；可在此切换超频或点击**重新检测**。显示真实亮环数及九环槽位列表，L9 的基准／量子／终末星位锚分别为 **96／168／240**。
- **配方树**：选择节点后查看算力门槛、前置、一次性信息费用和实际配方产物。悬停产物图标或内容摘要可查看详情，再支付解锁。仅选择节点不会购买，扣费与结果均由服务器确认。

总览与配方树随服务端同步等级实时换色：**L0～L3 青绿、L4～L6 蓝紫、L7～L9 金色**，无需重新打开界面。核心和建筑访问终端使用同一套**九环星仪示意、环列表和三类星位锚计数**，按服务端已验证的连续亮环数显示，未完成环保持锁定。界面没有独立星位锚页或结构投影按钮；搭建前请使用 JEI 结构预览，部署时使用星图定标器。

同一 ME 网络只采用**已成型、有电、频道有效的最佳引擎**提供生产增益：优先等级更高者，同级优先超频者。多座引擎的算力、并行、存储和速度**不会相加或叠乘**，拼接或堆叠结构也不会产生额外收益。界面数值描述当前打开的引擎，较弱引擎不会额外贡献一份加成；仅已成型或能打开界面，不代表增益已生效。

整机封存包含**中央全部 27 件：真实主核、22 个外壳和 4 个观测端口**。通过有效中央部件打开的界面仍属于同一主核，封存不会把这些部件留在原地。详见[折叠建筑与整机搬迁](folded_buildings.md)。

## 星位锚

**基准星位锚、量子星位锚、终末星位锚**安装在围绕核心的固定环形槽位，不再向四个方向堆柱。中央 3×3×3 与基座完整但没有亮环时为 L0；每完成下一环升一级，直到 L9。以下星环判定均以中央结构和基座保持完整为前提。

| 环 | 所需星位锚 | 本环方块数 |
| --- | --- | ---: |
| 1 | 基准 | 24 |
| 2 | 基准 | 32 |
| 3 | 基准 | 40 |
| 4 | 量子 | 48 |
| 5 | 量子 | 56 |
| 6 | 量子 | 64 |
| 7 | 终末 | 72 |
| 8 | 终末 | 80 |
| 9 | 终末 | 88 |

每一环必须填满对应阶位的槽位，不能混搭或用其他阶位替代。位置随核心水平朝向旋转；真实功能锚保持在搭建坐标，不要跟着动画中的环面移动方块。缺块、材质错误或归属冲突会使该环及其外侧环不计入等级，内侧已确认完整的环仍可计入。尚未加载或重载后尚未由服务端复核的环，不会凭旧存档记录提供增益。

### 亮环与有效算力

等级由**从第一环开始连续完整的亮环数**决定，有效算力使用下表中该等级的固定值，不再按旧锚柱的递进封顶公式计算。零散锚、柱式堆叠或只完成外环都不能跳级；界面的有效锚数量仍是**方块数**，不是算力值。

## 网络增益与超频

下表为**未超频的常态能力**。合成器并行按每台受支持的构序合成设备计算；CPU 并行与合成存储按万物演算核心的每颗 CPU 计算。这里的合成存储**不是普通 ME 物品存储空间**。构筑井按速度倍率缩短配方耗时。

| 等级 | 算力门槛 | 合成器并行 | CPU 并行 | CPU 合成存储 | 构筑井速度 |
| --- | ---: | ---: | ---: | ---: | ---: |
| L1 | 240 | 4,096 | 512 | 1 GiB | ×2 |
| L2 | 560 | 16,384 | 1,024 | 4 GiB | ×3 |
| L3 | 960 | 65,536 | 2,048 | 16 GiB | ×4 |
| L4 | 5,760 | 262,144 | 4,096 | 64 GiB | ×8 |
| L5 | 11,360 | 1,048,576 | 8,192 | 256 GiB | ×12 |
| L6 | 17,760 | 4,194,304 | 16,384 | 1 TiB | ×16 |
| L7 | 89,760 | 16,777,216 | 32,768 | 4 TiB | ×32 |
| L8 | 169,760 | 67,108,864 | 65,536 | 16 TiB | ×48 |
| L9 | 257,760 | 268,435,456 | 131,072 | 64 TiB | ×64 |

对 `L = 1..9`，合成器并行为 `4,096 × 4^(L−1)`，CPU 并行为 `512 × 2^(L−1)`，CPU 合成存储为 `1 GiB × 4^(L−1)`。**L1–L6 使用物理 CPU，L7 起使用虚拟 CPU。** 没有完整亮环（L0）或同网没有有效引擎时，机器保留未受引擎辅助的基础能力。

**深度研究只提升构筑井并行，不再缩短配方时间。** 默认基础耗时为 **400 tick（20 秒）**。有有效引擎时，实际耗时为 `ceil(基础耗时 / 速度倍率)`，最少 1 tick；配方单独指定耗时时，以配方值代替 400。例如，默认配方在常态 L1 耗时 200 tick，常态 L9 耗时 7 tick。

### 超频

超频会持续从**同一 ME 网络的存储中真实扣除星讯流**，与 16 AE/t 闲置耗能、研究的一次性支付分别计算。界面以 **bit** 显示实际可用库存，以 **bit/t** 显示实际消耗；未超频时，生产增益不消耗星讯流。

- 消耗为 `1 << L` bit/t，L1 至 L9 依次为 **2、4、8、16、32、64、128、256、512 bit/t**。由被选中的最佳引擎为网络增益付费，不是每台受益机器各扣一份。
- **L1–L8** 超频将四项增益全部翻倍：合成器并行、CPU 并行、CPU 合成存储、构筑井速度。不会把算力翻倍，也不能绕过研究门槛。
- **L9** 在持续付费超频时提供**无限合成器/CPU 并行、无限 CPU 合成存储与构筑井 1 tick 加工**；未超频的 L9 仍是上表的有限能力。
- 开启超频至少要有足够支付一个 tick 的星讯流，之后每 tick 都必须实际付款；余额不足会关闭超频，结构失效或网络离线也会关闭。引擎仍有效时退回常态有限增益，离线或结构损坏时不提供增益。永久研究解锁不会因此丢失。

## 团队永久研究

**配方树**有五个团队永久节点。解锁需要引擎已成型且在线，达到相应算力门槛、完成前置，并从 ME 信息库存中**一次性付费**。算力只是门槛，**不会被扣除**；超频不改变门槛或解锁状态。

进度按引擎绑定的团队保存（无团队时使用放置玩家身份），同队引擎共享，拆除引擎、区块卸载或服务器重启都不会清除。使用受门控的构筑井配方时，其 ME 网络仍须有有效引擎提供该团队的解锁状态；配方原有的物质研究要求也仍然适用。

| 节点 | 等级／算力门槛 | 一次性费用 | 前置 |
| --- | --- | ---: | --- |
| 星算基础（`foundation`） | L1／240 | 512 bit | 无 |
| 量子材料（`material`） | L3／960 | 2,048 bit | 星算基础 |
| 量子构序（`quantum`） | L6／17,760 | 8,192 bit | 量子材料 |
| 终熵材料（`terminal`） | L7／89,760 | 16,384 bit | 星算基础 |
| 超限构筑（`transfinite`） | L9／257,760 | 65,536 bit | 量子构序**与**终熵材料 |

各节点对应以下配方，界面会从服务器当前配方解析真实产物：

- **星算基础**：构序自动合成器，以及构序阵列外壳、量子水晶、相位玻璃、稳定器。
- **量子材料**：**量子星位锚**、分子构序重写阵列、构序重写核心、构序阵列控制器、装配矩阵构序重写核心。
- **量子构序**：**终末星位锚**、万物演算核心、演算核心框架、演算结构玻璃、演算晶体尖塔、数据纠缠节点、演算能量稳定器、构序输出节点。
- **终熵材料**：无限构序存储矩阵、无限并行矩阵、全知演算矩阵。
- **超限构筑**：超限算枢。

星位锚升级刻意避开循环门槛：**先用 96 个基准星位锚完成前三环，达到 L3 后通过「量子材料」解锁量子星位锚；再保留前三环并完成第 4～6 环，达到 L6 后通过「量子构序」解锁终末星位锚。** 不需要先有正在解锁的高阶星位锚。

## 获取

先从星髓晶簇采集水晶，在压印器加工水晶粉和星图处理器，再用 **AdvancedAE 反应仓** 制作星髓合金锭。引擎核心、外壳、观测端口和基准星位锚都在 **工作台** 合成，两种实体基座按其配方准备。量子星位锚和终末星位锚仍在构筑井加工，需要完成 **一阶：AE 材料构筑** 研究，**并解锁上述各自对应的引擎永久节点**。这条初始材料链不需要无瑕母岩或星讯流；引擎节点解锁与可选超频则需要消耗星讯流。

### L1/L2/L3 完整建筑包与 JEI 预览

1. 在 JEI 的**天体仪结构**分类选择 L1、L2 或 L3。三条结构配方分别显示**全部建材和对应包裹产物**，包括中央全部 27 件和完整实体基座，不是只显示新增一环。
2. 预览操作与其他建筑相同：**左键拖动旋转、右键拖动平移、滚轮缩放**，用分层按钮查看各层，也可重置视角。基座的负 Y 层同样在预览中。
3. 将**空间折叠装配器**接入 ME，在网络中订购所需包裹。它共提供七种包：物质构筑井、构序阵列、万物演算核心、视界奇点天枢，以及天体仪 L1/L2/L3。每单实际消耗下表中的完整材料；创造模式物品栏也提供这三种天体仪包。

把包裹放在背包中，用**星图定标器右键选址**，选择包裹、朝向和基面坐标后确认展开。基面 Y 是最低实体基座层，**核心 Y = 基面 Y + 37**。Esc 只收起面板；再次右键重开原定点，只有“取消定点”才允许换址。完整操作见[折叠建筑与整机搬迁](folded_buildings.md)。

### 三阶星位锚

基准星位锚在 **工作台** 用合金锭 ×4、外壳 ×2、星髓晶体 ×2 和星图处理器 ×1 合成，每次产出 **9 块**；这是配方批量，不是单环所需数量。量子星位锚和终末星位锚在 **构筑井** 分别消耗 9 块前一阶星位锚，升级产出 9 块。除一阶：AE 材料构筑研究外，量子星位锚配方还需**量子材料（L3／960 算力、2,048 bit）**，终末星位锚配方还需**量子构序（L6／17,760 算力、8,192 bit）**，并完成树中列出的前置。
