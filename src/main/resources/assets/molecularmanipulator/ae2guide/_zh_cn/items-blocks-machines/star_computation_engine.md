# 星算引擎

星算引擎是一座 **3×3×3** 多方块结构，由核心、外壳和观测端口组成。成型后，整机会切换为全新的连续机械外观，带有透镜核心、扫描光带和星讯流发光动画；观测端口会被成型面板覆盖，不再透明。正面透镜的方向由中心核心的朝向决定。拆开结构后，各部件恢复未成型外观。

## 搭建

1. 把**星算引擎核心**放在 3×3×3 的中心。
2. 在中间一层的四个侧面中心放**星算观测端口**。
3. 其余 22 个位置放**星算引擎外壳**：
   - 顶层 9 个外壳
   - 中间层 4 个角落外壳
   - 底层 9 个外壳
4. 结构完整后会自动成型，**成型本身**不需要右键或供能；网络增益与研究操作则需要有电、已分配频道的有效 ME 连接。

| 部件 | 数量 |
| --- | --- |
| 星算引擎核心 | 1 |
| 星算观测端口 | 4 |
| 星算引擎外壳 | 22 |

### 九环天体仪预览模式

普通核心用上面的结构就能成型，不需要额外底座。九环预览是**可选玩法**：用 `entropy_armillary_l0`～`entropy_armillary_l9` 模板放置的核心，还必须在其下方搭建**实体镂空环架底座**；传统锚柱引擎不需要。

**搭建底座**

- 用 520 个**熵环天体仪雕花基座**和 408 个**熵环天体仪金边基座**，合计 **928 个真实方块**；普通金块和引擎外壳不能替代。
- 以核心为原点计算水平偏移 `x`、`z` 和半径 `r = sqrt(x² + z²)`。底座外径 **37 格**（半径 18），只占 Y=-37、-36、-35、-34 四层，中央 `r <= 5` 的竖井四层全空。

| 相对核心 Y | 实体方块轮廓 | 方块数 |
| --- | --- | ---: |
| -37 | 反重力环 `7 < r <= 10`、外环 `15 < r <= 18`，加上 `5 < r <= 18` 且满足 `abs(x) <= 1` 或 `abs(z) <= 1` 的四向 3 格宽窄桥 | 552 |
| -36 | 中圈 `12 < r <= 14` 与井沿 `5 < r <= 7` | 240 |
| -35 | 仅井沿 `5 < r <= 7` | 68 |
| -34 | 仅井沿 `5 < r <= 7` | 68 |

- 各环与井沿的外缘一格宽、四向窄桥的中线用金边，其余用雕花基座；精确布局可参照模板。
- **缺一块或放错材质都会停止成型和增益**，补齐后自动恢复；右击未成型的核心，会告诉你缺什么方块、在哪个坐标。

**成型后的样子**

- 未成型时底座就是冷灰石板／深蓝灰细金边的普通方块。成型后只隐藏**这 928 个底座方块**的外观，改为显示悬浮金属环架、正面悬浮宝石和能量井；这些方块的碰撞和掉落都保留，拆开结构或移除核心即恢复原貌，材料不损失。**环与环之间的空隙是真正空的**，不会像旧版那样撞到实心台阶；但旧布局留下的方块或你自己额外放的方块仍然有碰撞，需要手动拆掉。
- 环体按服务端确认的连续亮环数逐个出现：L0 不显示，L3 显示前三环，L9 显示全部九环。已点亮的环面会绕核心翻转、进动，环上的镶嵌水晶跟着环一起动。基础／量子／终末三阶分别使用青绿、紫、金材质。
- **120 格刻度盘**悬浮在核心下方、微微倾斜，缓慢自转；其余底座部件不动。
- 真实功能锚仍在原搭建坐标，供选取、接线和升级，旁边的小标记不随环运动。

**动态效果**

客户端**动态效果**设置（0 关闭、1 精简、2 完整）控制动画和细节。**至少点亮一环**后，可启用刻度盘旋转、星云向内流动、水墨井面和数据雨：

- **等级 0**：保留静态整机、星云和底座。
- **等级 1**：启用上述效果，使用精简细节。
- **等级 2**：增加更细的细节、环带镶嵌水晶和近距离锚位辉光。

流动速度跟随引擎的真实状态：断网／待机时 **0.35 倍**，作为有效 ME 网络中选中的在线引擎时 **1 倍**，正在真实付费超频时 **2 倍**；信息耗尽或断网会降回慢档。效果会随视距和世界雾效淡出。

**已有世界**

只升级 JAR 不会改动存档：不会拆掉旧方块，也不会生成新方块。旧版用实心台阶搭的预览需要按上表手动重建，并拆掉多余方块。旧底座里以隐藏成型状态（`formed=true`）保存的方块，在区块加载后会重新可见，方便你拆除；不会自动删除任何方块，材料照旧保留。

**模板重放只适合一次性的测试世界。** 10 个模板都是 **75×76×75**，核心在模板内坐标为 **(37,38,37)**，含 27 个引擎方块、504 个候选锚位和 928 个底座方块。若在**同一绝对模板原点**重放，还会把旧版 11084 个台阶占位中已退役的 **10156 个位置**、以及未使用的候选锚位写成空气，但不会清空整个包围盒。**这些写入会替换该位置上的任何方块，不只旧底座；切勿在主存档的建筑上重放模板。**

## ME 接网与界面

把真实 ME 线缆接到**已成型的外壳或观测端口**即可接网；已成型、有效附着的熵锚也提供同一核心的 ME 接口。整座引擎是**一个网络设备**，占用 **1 个频道**，闲置耗能 **16 AE/t**，不是每块外壳或熵锚各占一个频道。这是真实 AE2 接网，不是装饰性的连线指示。

右键**任意已成型的核心、外壳、观测端口，或有效附着的熵锚**，都会打开所属引擎的实时界面。界面只有**两个页签**：

- **总览**：显示结构与 ME 状态、有效序熵与等级、三类有效锚数量、四项网络增益图标，以及网络信息库存和实际 bit/t 消耗；可在此切换超频或点击**重新检测**。九环模式显示真实亮环数及九环槽位列表，L9 的基础／量子／终末锚分别为 **96／168／240**。
- **配方树**：选择节点后查看序熵门槛、前置、一次性信息费用和实际配方产物。悬停产物图标或内容摘要可查看详情，再支付解锁。仅选择节点不会购买，扣费与结果均由服务器确认。

总览与配方树随服务端同步等级实时换色：**L0～L3 青绿、L4～L6 蓝紫、L7～L9 金色**，无需重新打开界面。普通核心与九环核心统一使用**熵环天体仪九环示意、环列表和三类熵锚计数**，从建筑访问终端进入时也使用同一套界面，不再显示旧四向锚柱图。九环核心按服务端已验证的连续亮环数显示，未完成环保持锁定；普通核心的示意环数对应能力等级，当前环槽点表示有效序熵到下一等级的进度，**不代表实际放置的环形熵锚数量**。界面没有独立熵锚页、完整截面展示或结构投影按钮；更换界面不改变搭建规则，**传统锚柱仍必须连续且具有完整 3×3 截面**。

同一 ME 网络只采用**已成型、有电、频道有效的最佳引擎**提供生产增益：优先等级更高者，同级优先超频者。多座引擎的序熵、并行、存储和速度**不会相加或叠乘**。界面数值描述当前打开的引擎，较弱引擎不会额外贡献一份加成；仅已成型或能打开界面，不代表增益已生效。

## 熵锚

**基熵锚、量子熵锚、终熵锚**可以组成可选的 **3×3 截面锚柱**，从引擎的四个水平面向外延伸。熵锚不是引擎 3×3×3 本体成型的必需部件。

- 首层截面放在引擎外侧，紧贴外壳，不能留空隙。
- 每个截面需要 **9 块熵锚**；各层必须是连续、完整的截面，中间不能缺块或断层。
- 允许混用不同阶位，同一截面也可混搭；每块熵锚保留对应阶位的外观。
- 最外侧的完整截面显示端盖。水平延伸只检查已加载区块。

拆开引擎或断开锚柱后，受影响的熵锚会恢复原来的未成型外观。只有连接到引擎的完整、连续截面才计入有效熵锚与序熵；缺块或断层会使该截面及其外侧部分无法贡献。有效熵锚显示的是**方块数**，不是经过封顶计算的序熵值。

### 有效序熵与阶位封顶

每块有效熵锚按阶位贡献序熵，但三阶采用**递进封顶**：高阶在下一档上限内替代低阶贡献，而不是三档最大值独立相加。

| 熵锚 | 每块序熵 | 计入该阶后的上限 |
| --- | ---: | ---: |
| 基熵锚 | 10 | 900 |
| 量子熵锚 | 100 | 9,000 |
| 终熵锚 | 1,000 | 90,000 |

设有效基熵锚、量子熵锚、终熵锚的方块数分别为 `b`、`q`、`t`，按以下顺序计算：

```text
B = min(900, 10 × b)
Q = min(9,000, B + 100 × q)
E = min(90,000, Q + 1,000 × t)
```

`E` 就是引擎的有效序熵。例如，一层完整的 9 块基熵锚提供 90 序熵（L1），90 块基熵锚达到 900（L3）。有 90 块量子熵锚时，即使保留基熵锚，总值也封顶 9,000；有 90 块终熵锚时封顶 90,000，而不是 99,900。超出上限的有效熵锚仍可计入方块数，但不再提升等级。

## 网络增益与超频

下表为**未超频的常态能力**。合成器并行按每台受支持的构序合成设备计算；CPU 并行与合成存储按万物演算核心的每颗 CPU 计算。这里的合成存储**不是普通 ME 物品存储空间**。构筑井按速度倍率缩短配方耗时。

| 等级 | 序熵门槛 | 合成器并行 | CPU 并行 | CPU 合成存储 | 构筑井速度 |
| --- | ---: | ---: | ---: | ---: | ---: |
| L1 | 90 | 4,096 | 512 | 1 GiB | ×2 |
| L2 | 270 | 16,384 | 1,024 | 4 GiB | ×3 |
| L3 | 900 | 65,536 | 2,048 | 16 GiB | ×4 |
| L4 | 1,800 | 262,144 | 4,096 | 64 GiB | ×8 |
| L5 | 4,500 | 1,048,576 | 8,192 | 256 GiB | ×12 |
| L6 | 9,000 | 4,194,304 | 16,384 | 1 TiB | ×16 |
| L7 | 18,000 | 16,777,216 | 32,768 | 4 TiB | ×32 |
| L8 | 45,000 | 67,108,864 | 65,536 | 16 TiB | ×48 |
| L9 | 90,000 | 268,435,456 | 131,072 | 64 TiB | ×64 |

对 `L = 1..9`，合成器并行为 `4,096 × 4^(L−1)`，CPU 并行为 `512 × 2^(L−1)`，CPU 合成存储为 `1 GiB × 4^(L−1)`。**L1–L6 使用物理 CPU，L7 起使用虚拟 CPU。** 低于 90 序熵（L0）或同网没有有效引擎时，机器保留未受引擎辅助的基础能力。

**深度研究只提升构筑井并行，不再缩短配方时间。** 默认基础耗时为 **400 tick（20 秒）**。有有效引擎时，实际耗时为 `ceil(基础耗时 / 速度倍率)`，最少 1 tick；配方单独指定耗时时，以配方值代替 400。例如，默认配方在常态 L1 耗时 200 tick，常态 L9 耗时 7 tick。

### 超频

超频会持续从**同一 ME 网络的存储中真实扣除星讯流**，与 16 AE/t 闲置耗能、研究的一次性支付分别计算。界面以 **bit** 显示实际可用库存，以 **bit/t** 显示实际消耗；未超频时，生产增益不消耗星讯流。

- 消耗为 `1 << L` bit/t，L1 至 L9 依次为 **2、4、8、16、32、64、128、256、512 bit/t**。由被选中的最佳引擎为网络增益付费，不是每台受益机器各扣一份。
- **L1–L8** 超频将四项增益全部翻倍：合成器并行、CPU 并行、CPU 合成存储、构筑井速度。不会把序熵翻倍，也不能绕过研究门槛。
- **L9** 在持续付费超频时提供**无限合成器/CPU 并行、无限 CPU 合成存储与构筑井 1 tick 加工**；未超频的 L9 仍是上表的有限能力。
- 开启超频至少要有足够支付一个 tick 的星讯流，之后每 tick 都必须实际付款；余额不足会关闭超频，结构失效或网络离线也会关闭。引擎仍有效时退回常态有限增益，离线或结构损坏时不提供增益。永久研究解锁不会因此丢失。

## 团队永久研究

**配方树**有五个团队永久节点。解锁需要引擎已成型且在线，达到相应序熵门槛、完成前置，并从 ME 信息库存中**一次性付费**。序熵只是门槛，**不会被扣除**；超频不改变门槛或解锁状态。

进度按引擎绑定的团队保存（无团队时使用放置玩家身份），同队引擎共享，拆除引擎、区块卸载或服务器重启都不会清除。使用受门控的构筑井配方时，其 ME 网络仍须有有效引擎提供该团队的解锁状态；配方原有的物质研究要求也仍然适用。

| 节点 | 序熵门槛 | 一次性费用 | 前置 |
| --- | ---: | ---: | --- |
| 星算基础（`foundation`） | 90 | 512 bit | 无 |
| 量子材料（`material`） | 900 | 2,048 bit | 星算基础 |
| 量子构序（`quantum`） | 9,000 | 8,192 bit | 量子材料 |
| 终熵材料（`terminal`） | 18,000 | 16,384 bit | 星算基础 |
| 超限构筑（`transfinite`） | 90,000 | 65,536 bit | 量子构序**与**终熵材料 |

各节点对应以下配方，界面会从服务器当前配方解析真实产物：

- **星算基础**：构序自动合成器，以及构序阵列外壳、量子水晶、相位玻璃、稳定器。
- **量子材料**：**量子熵锚**、分子构序重写阵列、构序重写核心、构序阵列控制器、装配矩阵构序重写核心。
- **量子构序**：**终熵锚**、万物演算核心、演算核心框架、演算结构玻璃、演算晶体尖塔、数据纠缠节点、演算能量稳定器、构序输出节点。
- **终熵材料**：无限构序存储矩阵、无限并行矩阵、全知演算矩阵。
- **超限构筑**：超限算枢。

熵锚升级刻意避开循环门槛：**仅靠基熵锚即可达到 900 序熵，在「量子材料」解锁量子熵锚；仅靠量子熵锚即可达到 9,000 序熵，在「量子构序」解锁终熵锚。** 不需要先有正在解锁的高阶熵锚。

## 获取

先从星髓晶簇采集水晶，在压印器加工水晶粉和星图处理器，再用 **AdvancedAE 反应仓** 制作星髓合金锭。引擎核心、外壳、观测端口和基熵锚都在 **工作台** 合成。量子熵锚和终熵锚仍在构筑井加工，需要完成 **一阶：AE 材料构筑** 研究，**并解锁上述各自对应的引擎永久节点**。这条初始材料链不需要无瑕母岩或星讯流；引擎节点解锁与可选超频则需要消耗星讯流。
