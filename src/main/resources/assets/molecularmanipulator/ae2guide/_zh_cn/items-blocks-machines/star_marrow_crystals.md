# 星髓晶体、晶核与晶种

工作台先做出**原初晶核**，双生奇点观测环再把晶核结晶成**星髓晶种**；晶种最后用来转化母岩。星髓母岩会像赛特斯石英一样长芽，最终长出星髓晶簇。同一个观测环还能把**星髓晶体**直接转换成**星图电路板**，这是托架的第二种转换。

## 晶核与晶种配方

在工作台无序合成，材料与以前相同：

- 充能赛特斯石英水晶 ×1
- 天空石粉 ×1
- 紫水晶碎片 ×1
- 雪球 ×1
- 末影珍珠粉 ×1

产出 **原初晶核 ×2**。晶核不能直接拿去点母岩，要先在末地双生奇点观测环里结晶成星髓晶种。

## 双生奇点观测环：两种托架转换

前侧平台的两个托架有两种转换，操作完全一样，只是投入和产出不同。JEI 中可查看这两条加工；查询晶种或电路板的配方，或查看晶核、水晶、供电台及托架的用途即可找到。

| 转换 | 投入（输入托架） | 产出（输出托架） | 一批数量 | 用时 | 电力 |
| --- | --- | --- | --- | --- | --- |
| 晶核结晶 | 原初晶核 | 星髓晶种 | 任意 N 个，最多 64 个，N:N | 整批共 160 tick（8 秒） | 沿用观测环供电，整批基础 16 AE/t；默认配置下一批约 2,560 AE，与 N 无关 |
| 电路板转换 | 星髓晶体 | 星图电路板 | 任意 N 个，最多 64 个，N:N | 整批共 160 tick（8 秒） | 同上，整批基础 16 AE/t，与 N 无关 |

两种转换共用的规则：

- **同一批只能放一种输入**：晶核和水晶不能混在同一批里。要换另一种，先把输入托架里尚未开始的存货取回。
- **输出必须装得下**：输出托架要能一次放下整批 N 个产出，连同托架里已有的物品；只有物品相同、组件也相同时才能合并进去。放不下，或者托架里已有不兼容的物品，就原地等待。
- **全程手动**：每批都要自己右键开始，成品也要自己右键取出，做完不会自动接着开下一批。

下面的操作步骤以晶核结晶为例。做电路板时，把“原初晶核”换成“星髓晶体”、“星髓晶种”换成“星图电路板”即可，其他完全一样。

1. 手持原初晶核右键**输入托架**，会尽量放入，最多 64 个；尚未开始的存货和已经锁定的整批合计不超过 64 个。
2. 空手右键输入托架开始。**整叠晶核会作为一整批一起锁定**，共用同一个 160 tick（8 秒）周期，一起变成 N 个晶种，整批同时处理。
3. **输出托架必须能一次装下整批 N 个晶种**（连同托架里已有的晶种），才会开始或继续。装不下就原地等待，不会部分完成。完成时 N 个晶种一次性放入输出托架。
4. 空手右键**输出托架**，取走整叠星髓晶种。
5. 想取回还没开始加工的晶核，**Shift + 空手右键**输入托架。这个操作只拿尚未锁定的新存货；已锁定的一整批会保留，暂停后恢复时仍按整批继续。每批都要手动开始，做完不会自动接着开下一批。

断电、供电台或观测环连接断开、没有输出托架，或输出托架剩余空间放不下整批时，进度会原地暂停，不会部分完成，也不会多产出；恢复后接着做。输入托架里尚未开始的存货、正在加工的一整批晶核、输出托架里的晶种及当前进度都会存档；打掉输入托架会把尚未开始的存货和整批加工中的晶核一起掉落，打掉输出托架会掉落晶种。托架没有 GUI，也没有接入漏斗或 ME 物品自动化。以上暂停、存档和掉落规则对晶核结晶和电路板转换都适用。

动画中，整批共用一个代表影像，数量显示为 N。第 0–72 tick 整批晶核保留在输入托架上进行稳定；第 72–112 tick 代表整批的晶核影像飞入黑洞；第 112 tick 整批 N 个晶种才在白洞一侧出现并飞向输出托架；第 160 tick 一次性放入 N 个星髓晶种。做电路板转换时，动画里的代表影像换成星髓晶体，产出换成电路板；电路板同样是飞入黑洞、被吸收之后才在白洞一侧出现。两个托架都会显示物品图标和数量；晶核飞入黑洞前，输入托架的计数包含已锁定的整批，飞入后这一批不再重复显示，只显示新放入、尚未开始的存货。

已有存档中的双生奇点观测环不会被自动重建或覆盖。旧名称的方块、物品、托架库存、加工进度及结构记录会继续读取。早期没有存储的旧托架第一次被右键使用时会补上存储，之后可以正常加工。

## 转化母岩

1. 准备 ExtendedAE 的**恩特罗化福鲁伊克斯母岩**（完全、多半、半、几乎未恩特罗化）。
2. 手持星髓晶种右键母岩。每次消耗 1 个晶种（创造模式不消耗），母岩下降一级：
   - 完全 → 多半 → 半 → 几乎未恩特罗化
   - 几乎未恩特罗化 → **重损星髓母岩**
   - 重损 → **破损星髓母岩**
   - 破损 → **微瑕星髓母岩**
3. 晶种最多只能到**微瑕**，不会继续变成无瑕。要拿无瑕母岩，改用点着的[绿火灯笼](green_fire_lantern.md)。

> 没有安装 ExtendedAE 时，晶种仍可修复已有的星髓母岩，但不能转化恩特罗母岩。

## 母岩等级

| 等级 | 说明 |
| --- | --- |
| 重损星髓母岩 | 最低级，长芽时不会继续掉级 |
| 破损星髓母岩 | 长芽时可能掉到重损 |
| 微瑕星髓母岩 | 长芽时可能掉到破损；晶种最高只能到这里 |
| 无瑕星髓母岩 | 永不掉级；通过绿火灯笼的模拟获取（见下文） |

每次成功长芽，母岩有约 **1/12** 概率掉一级。重损不再下降，无瑕永不掉级。

## 生长与采集

母岩的六个面都可以长芽，顺序是：

**小星髓晶芽 → 中星髓晶芽 → 大星髓晶芽 → 星髓晶簇**

用镐采集成熟晶簇：

- 不带精准采集：掉落 **3 个星髓晶体**，受时运影响
- 带精准采集：掉落晶簇本身，便于搬运或装饰；持续产出水晶仍需母岩长芽

## 材料

| 物品 | 用途 |
| --- | --- |
| 原初晶核 | 工作台产物；在双生奇点观测环结晶为星髓晶种 |
| 星髓晶体 | 晶簇的主要产物，星算系列的基础材料；也可在观测环转换成星图电路板 |
| 星髓晶粉 | 压印器将星髓晶体磨成粉，用于合金化 |
| 星髓合金锭 | AdvancedAE 反应仓合金化加工，作为引擎与熵锚的结构材料 |
| 星图电路板 | 双生奇点观测环把 1 个星髓晶体转换成 1 个电路板，不再用压印器压制 |
| 星图处理器 | 电路板、红石与硅板在压印器组装，用于引擎和熵锚 |

### 水晶粉与合金锭

不放模板时，压印器将 **1 个星髓晶体加工成 1 个水晶粉**。在 **AdvancedAE 反应仓** 中投入水晶粉 ×4、铁锭 ×4、福鲁伊克斯粉 ×1、天空石粉 ×1 和 **500 mB 水**，总能耗 **51,200 AE**，产出 **4 个星髓合金锭**。反应仓加工不需要构筑井研究；未安装 AdvancedAE 时，此合金配方不会加载。

### 电路板与处理器

星图电路板现在只在双生奇点观测环产出：输入托架投入 **1 个星髓晶体**，输出托架取出 **1 个星图电路板**。批量、用时和供电与晶核结晶相同，见上文“电路板转换”。原来用运算处理器压印模板在压印器压制电路板的配方已经移除。

再把电路板放在压印器上槽、红石放在中槽、硅板放在下槽，组装成星图处理器。这一步不消耗星讯流。

## 用绿火灯笼获得无瑕母岩

JEI 的“绿火模拟 · 无瑕母岩”页面显示微瑕母岩到无瑕母岩的获取方法，并将点燃的灯笼标为保留的工具。查询无瑕母岩的配方，或微瑕母岩、灯笼的用途即可找到。

微瑕母岩不用改变世界里的方块，也能拿到无瑕版本：手持有火的绿火灯笼进入模拟，再挖微瑕母岩，或用中键取方块（创造模式）。服务器会看这次操作是谁做的，把无瑕母岩方块交给该玩家。放下来的无瑕母岩就是永久的，不会再掉级。

你看到的无瑕只是自己的画面；世界里原来的方块仍是微瑕。长芽和原本的掉级概率照常在真实世界发生，所有玩家共享。如果在挖之前母岩已经掉级，拿到的就是掉级后的真实方块。普通玩家、假玩家和没有玩家归属的自动设备，仍按真实微瑕结算；普通玩家即使中键取方块也一样。普通镐子等会带上玩家归属的工具已经覆盖；直接改方块或背包的外部工具需要单独接入。

开模拟、看无瑕、挖无瑕都不耗燃料、不耗 AE，也不额外消耗星髓晶种；没有 12 格范围要求。操作和灯光范围见[绿火灯笼](green_fire_lantern.md)。
