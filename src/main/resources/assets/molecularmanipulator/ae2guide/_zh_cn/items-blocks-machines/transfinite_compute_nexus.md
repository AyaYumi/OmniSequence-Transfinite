# 超限算枢

## 用途：一块方块，承担整座演算核心的接单工作

超限算枢是单方块**合成 CPU**，也就是接收终端订单、安排制作顺序的设备。它提供[万物演算核心](omni_computation_core.md)的接单功能，省去大型建筑，但不会自己保存配方或制作物品。

上图是“算枢接 ME 线缆，再由终端下单”所需的物品。网络里还要有物品存储，以及真正制作配方的设备。**样板**是写好配方的卡片，放在构序阵列、重写设备或样板供应器里；原料和成品放在 ME 存储。

## 准备

- 在[构筑井](matter_fabrication_research.md)完成一轮**Ⅵ阶：超限集成工程**。
- 在达到 **L3** 的[星算引擎](star_computation_engine.md)研究页，主动解锁**单方块集成**，费用 **0 bit**。默认该节点只限制超限算枢和分子构序重写阵列的制作配方；达到等级后仍要点击解锁。
- 配方所需的 **AdvancedAE** 材料；默认算枢配方只在安装 AdvancedAE 时提供。
- 一个已供电的 ME 网络，带终端、物品存储、样板和实际制作设备。给算枢留 **1 个空闲频道**，即网络给设备的连接名额。
- 能持续供给默认 **16,384 AE/t 基础待机耗电**的电源，并为其余设备和制作留出余量。

## 步骤：接线后试一单

1. 放下算枢，从**任意一个面**接入 ME 线缆；六个面都可接线。
2. 把终端、ME 存储和实际制作设备接入同一网络，确认算枢取得电力和频道。
3. 在重写设备或构序阵列的主库放入“橡木原木 → 橡木木板”样板，并向 ME 存入至少 **4 个原木**。
4. 从终端请求 **16 个木板**，在合成确认页选择超限算枢作为 CPU，确认订单。
5. 打开 AE2 合成状态界面观察进度；完成后从 ME 取出木板。

算枢需要连接线缆或其他外部 ME 设备。只把多个算枢彼此贴着放，组成的孤立小团不能工作。

## 成功标志

- 合成确认界面能选择这台算枢。
- 测试订单完成，ME 中的 4 个原木被制作成 16 个木板。
- 算枢管理订单，制作设备动手，成品回到 ME 存储；算枢里无需放样板或原料。

### 小体积不等于默认无限

算枢和万物演算核心使用相同上限。**合成存储**是订单的工作空间，不是存储盘容量；**配方并行量**也不是独立订单数。

| 星算状态 | 算枢能力 |
| --- | --- |
| 没有在线有效星算引擎 | **1 MiB 合成存储、配方并行 16**，一次接一个独立订单。 |
| L1～L6 常态 | 合成存储和配方并行量增加，仍一次接一个独立订单。 |
| L7～L9 常态 | 可同时接多个独立订单，共享本机额度；L9 常态仍是有限上限。 |
| L9，开启且持续支付的超频 | 无限合成存储和配方并行上限；原料、电力、机器速度和输出空间仍决定实际产量。 |

L1～L8 超频持续消耗同网络的**星讯流**，把合成存储和配方并行量翻倍。多订单从 L7 开始，与是否超频分开判断。 星讯流不足就退出超频，恢复有限常态能力。 完整说明与联动机器的支持范围见[万物演算核心](omni_computation_core.md)。

## 排错

| 看到的情况 | 怎么处理 |
| --- | --- |
| 算枢放下后没有可用 CPU | 检查外部 ME 接线、电力和频道；几个算枢互相贴靠不能代替联网。 |
| 网络反复掉电 | 先保证算枢的基础待机耗电，再给网络其他设备和制作供电。 |
| 有 CPU 但找不到要做的物品 | 将样板放进实际制作设备或供应器，算枢没有样板库。 |
| 已有一单，不能接第二单 | 检查有效星算引擎是否已到 L7；基础并行 16 不代表能接 16 单。 |
| 大单提示存储不足或一直等待 | 先拆小单测试，再检查合成状态中的缺料、机器和回库空间；增加物品盘不能扩大合成存储。 |
| 制作算枢的配方不出现或锁定 | 确认安装 AdvancedAE，并同时完成井内“超限集成工程”和“单方块集成”许可；借用联网许可时保持提供许可的引擎在线。 |
| 离开基地后停止制作 | 算枢**不强加载区块**；持续工作需要保持所在区块加载。 |

## 下一步

- 缺配方或实际制作设备：先配置[分子构序重写阵列](molecular_sequence_rewrite_array.md)或[构序阵列](sequence_array_controller.md)。
- 想让常用成品自己补满：使用[分子自动合成器](molecular_auto_crafter.md)，不必反复给 CPU 下单。
- 想提高多订单和大单能力：提升同网络[星算引擎](star_computation_engine.md)，同时补足物品存储、能源和制作设备。

搬迁前先结清订单。正常拆下算枢会保留可恢复的任务和内容；重新放置并恢复在线 ME 连接后可继续。
