# Negative Entropy Engine

The Negative Entropy Engine is a **3×3×3** multiblock built from a core, casing and observation windows. Once formed, the shell is covered by one continuous machine panel, with the observation windows left visible at the centre of each side.

## Building

1. Place the **Negative Entropy Engine Core** in the center of a 3×3×3 volume.
2. Put a **Negative Entropy Observation Window** in each of the four side centers of the middle layer.
3. Fill the other 22 positions with **Negative Entropy Engine Casing**:
   - 9 casing blocks on the top layer
   - 4 corner casing blocks on the middle layer
   - 9 casing blocks on the bottom layer
4. The structure forms automatically. No right-click or power is required.

| Part | Amount |
| --- | --- |
| Negative Entropy Engine Core | 1 |
| Negative Entropy Observation Window | 4 |
| Negative Entropy Engine Casing | 22 |

## Current behavior

In the current version, forming the engine only changes its appearance. It has no GUI, power input or automatic conversion yet.

## Entropy Anchors

**Base Entropy Anchor**, **Quantum Entropy Anchor** and **Terminal Entropy Anchor** are decorative building blocks for the negative entropy series. They do not participate in the 3×3×3 formation check and currently have no survival recipe.

## Obtaining

The engine has no survival recipe in the current version. Use the creative inventory, or add a recipe through KubeJS in a modpack.
